# Scissione guidata

Versioned case evidence, professional decisions and separate value schedules for
the first Italian OIC partial proportional/new-beneficiary path. See
`skills/scissione-guidata/SKILL.md` and `references/data-contract.md`.

This component is embedded in Vera. It requires a running portable Studio Archive
engagement. It does not approve legal rules, sign, file, calculate tax eligibility
or cover other scissione configurations. Synthetic acceptance is not field testing.
