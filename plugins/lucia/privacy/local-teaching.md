# Local OpenAI teaching boundary

Impara con Lucia is available in desktop Codex and, with verified capabilities,
actual local ChatGPT Work on the same OS user. The shared stdlib desktop_teaching
runtime stores a Lucia-specific professional summary, lessons, examples, progress
and optional feedback locally. Exact product identity, enrollment, revisions,
paths, hashes and native chat tokens are mechanical checks; legal reasoning and
understanding remain with the native model and professional.

Native OpenAI processes spoken conversation, the loaded profile and selected
material. Local storage is not offline inference. No custom model/voice API,
Mparanza interview, tutorial telemetry, change request or tutorial receipt is
called. Helpers do not save audio or raw transcripts. Tutorial files remain below
the compatibility local-only marker, including the actual private portable ledger.
A selected real assignment follows its specialist's data and review contract;
teaching state remains local even after completion. No Claude Cowork teaching.
