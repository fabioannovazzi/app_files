# Lucia workflow catalog

Interpret the user's purpose with the native model, then read the selected skill
completely. These exact identifiers register capabilities; they are not keyword rules.

## Native document work

These professional workflows have no prepared teaching course in this release.
They are available for ordinary work, outside the prepared-course inventory below.

| Skill | Scope |
| --- | --- |
| `revisione-contratti` | Review a selected contract for the represented party with quoted clauses and proposed changes. |
| `confronto-documenti` | Compare selected versions or agreements with source-specific terms and explained differences. |
| `revisione-documentale` | Examine selected documents against common questions and deliver an evidence-linked matrix. |
| `redazione-da-modello` | Edit a copy of a supplied template using confirmed facts and a change register. |

## Existing workflows and internal support

- `apertura-pratica`: prepare a lawyer-reviewable opening dossier from selected evidence.
- `quesito-legale-fiscale`: research and answer a substantive legal or tax question with current authoritative sources and independent validation.
- `comunicazione-professionale`: prepare a source-bound professional communication for review.
- `presenza-digitale-studio`: build or revise the firm's informational website from verified facts.
- `legal-tax-answer-planner`: internal legal assignment and source-plan framing.
- `legal-tax-answer-review`: internal source and reasoning validation.
- `adversarial-opinion`: internal independent opposing legal inquiry.
- `studio-archive`: private client, matter, input and run lifecycle only.

## Learning

- `learn-with-lucia`: teach current workflows by native voice with a parallel visible working chat, first-use interview, 3–4 tailored lessons and reusable local examples.
Only Lucia's own installed operational skills are eligible. Explain requests
for another plugin's skills and offer relevant Lucia workflows without teaching
or silently substituting the other plugin.
The four document workflows are available for professional work; this release
does not include prepared teaching courses for them. Do not present an ordinary
document run as a validated course or mark it as completed teaching.
