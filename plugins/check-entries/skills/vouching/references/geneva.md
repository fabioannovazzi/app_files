# Geneva adaptation of the existing function

Use the existing supporting-PDF path for Geneva invoices and other evidence, with explicit source currency and reviewed journal lineage. Do not request FatturaPA first merely because it is the Italian intake default. Preserve the original file, source page/locator and extraction uncertainty. A QR payment section may support payment-reference checks, but it does not automatically supply all invoice evidence. No new Swiss-only function or unsupported native parser is added.

Official starting sources and the complete catalogue assessment are in Vera’s `references/localization/geneva/`. Verify current applicability for each actual case.
