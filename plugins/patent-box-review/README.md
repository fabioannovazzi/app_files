# Patent Box review — first integration

Ordinary software workflow in a bound Vera Studio Archive run. Codex reads only
selected documents, proposes structured facts and control decisions, and records
explicit operator review before generating a calculation and draft A/B dossier.
The bundled synthetic example is a technical acceptance case, not legal advice.

Real rules remain DRAFT. Reviewer identity is locally asserted in the existing
host workflow, not authenticated as a licensed professional. No output is a
signed dossier, tax return, certified entitlement or tax saving.

See `skills/patent-box-review/SKILL.md` for execution and
`references/implementation-status.md` for interface mapping and acceptance.
