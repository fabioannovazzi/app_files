La propietaria de Ciclo Arco quiere decidir si probar un servicio de recogida y devolución de bicicletas para reparación. Comparar un pequeño piloto con cita previa con el lanzamiento inmediato de un servicio diario. Destinataria: la propietaria. Entregable solicitado: un breve informe con recomendación, motivos, límites y siguiente paso.
Usar únicamente las notas de clientes y operaciones suministradas. No contactar con clientes, buscar datos externos ni comprometer gastos. Precios, costes, disposición a pagar y demanda general no están documentados: no preparar una previsión financiera.
