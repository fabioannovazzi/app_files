# Ciclo Arco

Paquet fictif pour apprendre le processus d’importation. Le texte a été rédigé pour la leçon : aucun audio n’a été enregistré ou transcrit par un service. La première note comporte une seule voix qui se présente comme Sara Campione. Les identités du second échange ne sont pas documentées ; conserver Voix 1 et Voix 2. Ne pas ajouter de jugements ou de décisions au dossier.
