# Geneva adaptation of the existing function

Use CH-GE and an explicit jurisdiction_basis for the company and mandate. Review organisational responsibilities, accounting processes, information flows, actual controls and decisions through the existing observations/findings/actions record. Obtain the applicable Swiss corporate/accounting basis and professional proportionality assessment. Do not apply Article 2086 of the Italian Civil Code or translate an Italian compliance conclusion. The source/decision integrity and unresolved-evidence controls remain the same. Output language does not select governing law; prior review jurisdiction must match.

Official starting sources and the complete catalogue assessment are in Vera’s `references/localization/geneva/`. Verify current applicability for each actual case.
