# Información para el sitio — caso ficticio

Studio Arco — despacho contable ficticio. Este documento describe únicamente un ejemplo didáctico, no profesionales reales.

Público: propietarios de pequeñas empresas italianas. Actividades que presentar: llevanza de contabilidad y preparación de declaraciones fiscales.

Contacto ficticio: segreteria@studio-arco.example. La secretaría responde de lunes a jueves, de 09:00 a 12:00. No se han facilitado dirección, inscripciones profesionales ni otras titulaciones.

El despacho aún no tiene sitio web. Se pide una página con presentación, actividades y contacto, legible también en teléfono. No hay logotipo ni fotografías; tipografía, colores y composición serán propuestas para revisar.

Material seleccionable solo para el sitio didáctico local. Sin formularios, reservas, portal de clientes, estadísticas, servicios externos ni publicación. Un sitio real exige verificar identidad, información profesional y avisos legales aplicables.
