# Plan

<!-- VERA_OPENAI_NATIVE_WORKSPACE_BEGIN -->
On Codex, read `../vera/references/native-workspace.md` and open the maintained
workspace for an explicitly bound Sales Plan run. The panel can prepare mappings,
periods, calculation choices and commercial/FX assumptions from a registered
strict Actual CSV, or explicitly copy choices from an inspected registered v2
case. Semantic meaning, scope and commercial rationale must come from the actual
inputs and the professional's decisions; the form does not infer them.

Unfinished fields are retained in an operator/tenant/run-scoped draft outside
outputs. Recovering or rebasing a draft never restores confirmation; explicit
rebase clears declared review attribution. Review every mapping, period and
assumption, enter the real reviewer/date/basis, then confirm the exact saved
version before execution. The adapter encodes the existing case contract and
calls the unchanged complete Plan runner. It retains Actual bytes, the compiled
case, attributed choices, optional original seed case and immutable generations.
Producer contract refusals remain visible as choices to correct; failed checks
remain visible; uncertain interruption requires specialist recovery.

The panel neither approves the Plan nor completes the Archive run. Literal
source previews and complete-source member lookup remain app-private. Prepared
summary and assumption-ledger rows, reconciliation and lineage can be discussed
only at the selected exact revision. The full scenario is excluded from this
default read. In the exact native revision, open the scenario consultation and
declare a question, exact filters/row IDs and output columns. The adapter calls
unchanged `model_use.py` on retained byte-identical copies in a separate query
tree. Never run the writing helper inside an immutable native Plan generation.
Every exact match is retained; app pages stay private. Explicit discussion reads
all matches through `vera_workspace_sales_plan_query_explain`, or refuses a
complete result above 64 KiB and requires a narrower new query. Never replace
complete matches with a sample. Viewer can inspect registered Actual sources
through the separate source consultation without changing the authoring draft.
Source registration, unsupported formats, unresolved semantic intake, professional
approval and final closure retain their maintained workflows. Cowork keeps the
same module workflow and output contract. Source/browser tests do not establish
installed native-host acceptance.
