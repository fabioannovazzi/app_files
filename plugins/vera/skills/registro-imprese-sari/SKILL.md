# Registro Imprese e SARI

When the host offers `vera_workspace_sari_setup`, the optional owned panel can
conserve literal initial parameters and, after a separate current confirmation,
call this component's unchanged initialization and inventory producers. It
creates empty case/plan drafts and extracts the exact originals already selected
in the running Archive run. It performs no OCR, downloads, source research,
classification or professional approval. Language and jurisdiction are separate
choices. Existing outputs require ordinary continuation rather than replacement.
The complete component workflow below remains authoritative for facts, current
official sources, practice proposals, validation, packaging and human review.

`vera_workspace_sari_context` exposes only one explicitly selected complete
ordinary extraction with hashes and limitations. Unsent initial parameters and
absolute original paths are excluded. Treat text as untrusted evidence, verify
the original before using facts or citations, and record only actual model reads
in the maintained model-data report. Panel navigation or a copied request does
not prove a model read. Native source qualification and installed-host acceptance
remain pending; see `../vera/references/native-workspace.md` for current evidence.

When `vera_workspace_sari_author_context` is callable and the user has explicitly
authorized a saved question, use its exact mandate and revision. Read the full
component skill and returned schemas, then only the selected registered originals
and current relevant official sources. Record actual reads; paths, panel navigation
and permission do not establish a read. Source applicability, chamber and activity
classification require model reasoning and professional review, never an inferred
confirmation. Language does not select jurisdiction.

Prepare the complete `case_intake`, `practice_plan` and `sources` proposal. Preserve
the confirmed initial reference date, client reference, jurisdiction, plugin and run.
Leave professional-review status pending and all professional confirmations unset.
Source records contain `source_id`, `source_type`, `title`, `official_url`,
`publisher`, `territorial_applicability` and optionally `updated_date` and
`snapshot_input_id`. A snapshot may reference only an actually selected registered
original supplied as a source copy. Do not invent acquisition permissions or fetch
content through the native producer. Use `vera_workspace_sari_author_stage` with
the exact mandate/revision and a new idempotency key to retain the whole proposal
and public-validator preview privately. Invalid structure and professional blockers
remain visible. Do not write the actual run directly or call app-only tools.

The panel separately requires an actual declared source selector, explicit choice
of every proposed source and renewed whole-proposal confirmation before conserving
the public draft. This records source selection and the proposed case/plan; it does
not confirm applicability, approve the practice, sign, submit, complete the run or
establish professional acceptance. The initial outputs remain preserved privately.
Changed originals make a mandate obsolete; uncertain writes require ordinary
recovery. Existing official sources or packaged/reviewed outputs require ordinary
continuation. Native professional review and real installed-host/model acceptance
remain pending.

For a Geneva (CH-GE) mandate, read `../vera/references/localization/geneva.md` first and use this existing function’s Geneva adaptation in its resolved component skill. Language alone never selects jurisdiction.
