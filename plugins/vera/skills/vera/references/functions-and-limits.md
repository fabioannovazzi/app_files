# Vera: functions and limits of use

The [workflow catalog](workflow-catalog.md) describes Vera's functions. The
[public function pages](https://mparanza.com/static/shared/vera/index.html?lang=it)
explain each process, its inputs, outputs and limits. Their final data section
describes what reaches the model, or explicitly states that the description is
being prepared. Do not infer a reviewed data path from another function.

Vera supplies local scripts and workflow instructions for professional work.
Local processing and reduced model inputs are defined per process. The selected
AI host can read the context needed for that process; local execution does not
mean that all work takes place without a model. Outputs remain working
materials for professional review and approval, not automatically validated
professional opinions or a certification of the studio's compliance.

Vera works with Codex, Claude Cowork and Google Antigravity. Its open-source
instructions and scripts can also be used in environments with local models;
available functions depend on the host's tools and the model's capabilities.
The host's account, contract and data controls are outside the plugin's checks.

The [optional integration guide](optional-integrations.md) describes five
anonymization engines. The user chooses whether and which engine to use.
Mparanza does not currently recommend one or validate the authors' effectiveness
claims. A connector's presence does not establish that its output is anonymous.

The [report contract](model-data-report-contract.md) separates the local report
from the technical receipt. Vera's receipt-enabled report command automatically
sends four fields: schema version, random receipt ID, Vera version and SHA-256
digest of the report. It sends neither the report nor client documents. Reading
an existing report, the generic Studio Archive local report helper, and the
explicitly local onboarding path do not request server stamping. The receipt
establishes existence, server time and integrity, not provider delivery or
legal compliance. Hosting and retention are described in the
[receipt notice](https://mparanza.com/zero-retention#run-receipts).

Vera is free software under AGPL-3.0-only. Its use does not include a support
commitment or service level unless separately agreed in writing. The
[terms](https://mparanza.com/terms#vera-functions-and-limits) and the
[public conditions of use](https://mparanza.com/static/shared/vera-compliance/index.html#condizioni-uso)
describe these boundaries. The function-by-function AI Act analysis is still
pending under G1.12 in the public comparison; this alignment of descriptions
does not constitute that assessment or establish approval for a high-risk use.
