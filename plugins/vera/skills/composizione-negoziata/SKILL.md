installed package, or `../../../composizione-negoziata` in repository source.
Read that module's `skills/composizione-negoziata/SKILL.md` completely and follow

launcher. Role and jurisdiction are independent of output language.

legal answer or a review of an actual concordato preventivo. Preserve separate

## Optional native CNC workspace

When the installed host exposes `vera_workspace_open`, the CNC panel may resume
an owned maintained Archive run. The adapter in `scripts/native_cnc.py` and
`scripts/native_cnc_bridge.py` reuses the module's ordinary case validator,
snapshot writer and complete memo renderer. Keep the full specialist instructions
above: this panel does not determine admissibility, independence or legal meaning.

The panel retains a literal question, explicit advisor/esperto role and selected
original receipt IDs. Saving an incomplete draft does not authorize model reads.
Renewed source confirmation issues a mandate for those originals and the exact
existing case. `vera_workspace_cnc_author_context` returns their paths and hashes
only after an explicit request. Read the actual granted files and record actual
reads in the run's normal model-data report; a mandate is not evidence of a read.
Unsent local reviewer names, reasons and confirmation references stay private.

Use `vera_workspace_cnc_stage` for the complete ordinary proposal, with empty
`reviews`, explicit granted citations and model-authored content/dependencies/
next action. The panel shows the whole proposed update and resulting case.
Separate renewed confirmation conserves its ordinary request, snapshot and memo;
it does not approve their professional content or complete the run. Exact node
consultation shows retained version-bound decisions and dependency staleness.
Stale nodes require reanalysis. Local accepted/rejected/changes-requested
readbacks require separately saved declared attribution, actual confirmation
reference and timezone-aware time, then renewed confirmation. Their authority
remains `record_only_identity_not_verified`; they do not approve a handoff.

Authenticated Mparanza review remains an explicitly chosen optional route. The
native helpers `scripts/native_cnc_authenticated.py` and
`scripts/native_cnc_authenticated_bridge.py` prepare the ordinary public
`--review-node` local file and retain an explicitly chosen receipt/reason draft
privately. Neither preparation nor draft saving contacts the service. Only the
professional signs in, selects the local file and confirms on the fixed hosted
page; the assistant must never perform those actions as the reviewer.

Renewed exact saved-receipt confirmation chooses verification against the fixed
HTTPS Mparanza endpoint. Only the opaque receipt UUID and complete-receipt digest
are sent. The unchanged public CNC verifier/writer independently binds the
retained server account, role, case, node version and decision. Successful import
keeps the actual server receipt, ordinary request, snapshot and memo in the same
running run. Service refusal/unavailability leaves authenticated attribution
pending and ordinary drafting available. Later interruption leaves an uncertain
intent and blocks repetition/closure; use the ordinary specialist recovery route.
No account authentication proves qualification, independence, signature or
external authority. Unsent receipt/reason drafts are excluded from model context.

Current source has incorrect lock and binding arguments in this new adapter,
so preparation/import remain unqualified. A separate two-argument correction

Do not describe this native route as accepted or bypass its locks/state.
Preserve source/case history and the ordinary file fallback.
No automatic case reconciliation or recovery is
provided. Completed runs permit consultation only. Native tools and panels may
be unavailable in an installed chat: continue the complete file-based Cowork or
Codex route without requiring this interface. Browser/protocol tests do not prove
installed-host, actual-model-read or professional acceptance.

`scripts/native_cnc_history.py` adds optional readonly history tools. The panel
lists thirty exact engagement revisions per page, newest first, including
revisions in other managed runs of the same engagement. Selected complete cases
retain their old nodes, source references, explicit dependency staleness and
version-bound reviews. Even the latest history view is readonly; new decisions
require the current node's separate review route. The outputs tool reads the
actual complete ordinary snapshot JSON and memo bytes with SHA receipts. Missing
memos are reported without regenerating files. Changed bytes or foreign case
references are refused. Consultation does not rewrite or complete a run.

An explicit `vera_workspace_cnc_history_context` call returns the whole selected
historical case within 64 KiB. Oversized cases are refused rather than truncated;
the complete private case/output view remains bounded to 2 MB. This context may
include confidential case content and already conserved reviewer identities and
reasons, but excludes unsent private drafts and absolute original-file/output
paths. Original evidence requires a separate explicit mandate. Record actual
case reads in the ordinary model-data report. Retained authenticated decisions
are shown as stored; this reader does not independently reverify their server
receipts or authenticate the reviewer again.

Current native source cannot consult or cancel an older open mandate after another
mandate creates a new case revision; that older mandate also blocks output
closure. A separate cancellation-only correction has passed candidate tests but
remains unapplied pending the AGENTS.md exception. Do not claim the native CNC
lifecycle complete or silently edit its private state to bypass this boundary.
