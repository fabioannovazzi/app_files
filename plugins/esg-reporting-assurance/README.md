# ESG evidence foundation

First implementation tranche of Francesco Giraldo's contributor proposal,
recovered from the ESG Discord channel on 29 September 2026. This component is
bundled by Vera and uses the existing Studio Archive. See the complete skill.

Implemented: recoverable case identity, exact CSV/text provenance, versioned
source metadata, decisions bound to exact versions, transitive stale status,
idempotent mutations and immutable JSON/Markdown partial drafts.

Not implemented: legal qualification, complete datapoint catalogues, ESG metrics,
full VSME/ESRS reporting, taxonomy, assurance procedures/opinions, final Office/PDF
renderers, specialist judgment or authenticated professional signatures.

Configuration files retain contributor provenance and remain unapproved seeds.
The new foundation schema is a scoped adaptation of the proposed data contract,
not a claim to implement every entity in the 2026-09-20 developer pack.
