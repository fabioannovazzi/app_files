# Geneva adaptation of the existing function

Use the same forecast and update method with one explicit reporting currency, EUR or CHF. All input tables must use that currency; an optional per-row currency must match. No implicit FX conversion is performed. Initial/updated cash, settlement allocations, noncash changes, retained decisions and scenario comparisons use the same exact arithmetic. HTML, Markdown, XLSX and the review UI display the selected currency. Source maps and cash-flow assumptions require review. The existing review interface and fixed prose remain Italian; author the accompanying professional explanation in the chosen language and do not claim a fully French Treasury interface.

Official starting sources and the complete catalogue assessment are in Vera’s `references/localization/geneva/`. Verify current applicability for each actual case.
