Usare le skill dello studio

Installa la tua skill nell’app in cui lavori e richiamala direttamente. Per usarla non occorre invocare Vera.

Prima di iniziare

Chiedi a chi mantiene la skill il pacchetto completo, il nome esatto e l’app per cui è stato preparato. Una skill contiene un file SKILL.md con istruzioni, nome e descrizione, ed eventualmente modelli, riferimenti e script. Un PDF di procedura, da solo, è un documento: non è una skill installata.

Una skill che funziona in Claude va verificata separatamente in Codex: script, strumenti richiesti e modalità di accesso possono differire. Questa guida non certifica la compatibilità delle skill dello studio. Non devi riscriverle da solo: chiedi al loro gestore una versione adatta alla tua app.

Claude e Cowork

  1. Apri Personalizza (Customize) → Skills. Premi + → + Create skill → Upload a skill e carica lo ZIP della skill fornito dal gestore.
  2. Lo ZIP deve contenere la cartella della skill con il suo file di istruzioni e tutte le risorse. Non caricare soltanto un modello o il file di istruzioni separato dal resto.
  3. Abilita la skill nell’elenco. Se mancano queste opzioni, verifica in Settings → Capabilities che Code execution and file creation sia attivo; con un account di studio chiedi all’amministratore di verificare le autorizzazioni per le skill.
  4. Apri una nuova conversazione o attività Cowork e chiedi esplicitamente di usare la skill con il suo nome. Usa questo esempio sostituendo il nome inventato e allegando un documento di prova:
Usa la skill «revisione-avvisi-studio» per questo documento di prova. Leggi le sue istruzioni e applica la procedura dello studio. Se non trovi la skill o manca uno strumento, segnalalo prima di procedere.

Codex sul computer

  1. Fornisci a Codex la cartella completa della skill o il suo percorso sul computer. Per l’installazione personale puoi chiedere: «Installa questa skill nella mia cartella personale ~/.agents/skills/, mantenendo istruzioni e risorse. Verifica nome e descrizione nel file SKILL.md».
  2. Il percorso finale è ~/.agents/skills/nome-skill/SKILL.md. Per una skill limitata a un progetto si usa invece .agents/skills/nome-skill/SKILL.md dentro quel progetto. Lo ZIP va estratto: non basta allegarlo alla conversazione. Se non sai quale cartella usare, fatti assistere dal gestore.
  3. Apri un’attività locale e controlla che la skill compaia tra quelle disponibili. Se non compare dopo l’installazione, riavvia l’app. Questa installazione sul computer non la rende automaticamente disponibile nella chat web, in cloud o ai colleghi.
  4. Nel selettore delle skill dell’app ChatGPT digita @ e scegli la tua skill. Nel terminale Codex o nell’estensione IDE usa /skills oppure $ seguito dal nome. Seleziona la skill effettivamente disponibile, poi descrivi il lavoro e fornisci i materiali.

Scegliere la propria skill

Se vuoi il metodo dello studio, richiama quella skill. Se vuoi un flusso di Vera, richiama Vera o la sua funzione. Installare entrambe non impone di usare Vera e non richiede di copiare la tua skill nel plugin Vera.

Collegare Second Brain dà accesso ai documenti: non installa né seleziona le skill. Se la tua skill deve consultarlo, il connettore e gli strumenti necessari devono essere disponibili nella stessa attività. Specifica l’archivio e il ramo da consultare.

Verificare che funzioni

Fai una prova con dati inventati. Controlla prima che la skill sia installata e attiva, poi cerca nella conversazione l’indicazione di caricamento delle istruzioni o la lettura del suo SKILL.md, quando l’app la mostra.

Confronta il risultato con i passaggi e il modello di output previsti dalla skill. La sola frase «ho usato la skill» non è una prova. Se l’app non mostra il caricamento, quel dettaglio resta non verificato; chiedi al gestore di controllare con te.

Se qualcosa manca

Skill assente? Verifica account, cartella o caricamento ZIP e stato di attivazione. Due skill con lo stesso nome? Controlla quale hai selezionato. Uno script o un connettore non funziona? Comunica al gestore app, sistema operativo ed errore: l’installazione delle istruzioni non garantisce tutte le dipendenze.

Passaggi verificati sulla documentazione ufficiale il 2 ottobre 2026. Nomi dei menu e disponibilità possono cambiare con versione, lingua e account.

Quali dati arrivano al modello

Questa pagina non installa skill e non legge file. Quando usi una skill, il nome e la descrizione possono essere forniti al modello; le istruzioni caricate, i riferimenti letti, i materiali della richiesta e gli output degli strumenti possono entrare nel contesto. Gli script possono elaborare file sul computer, ma questo non rende l’intero lavoro solo locale. Il percorso effettivo dipende dalla skill e dall’app: chiedi al gestore quali file, strumenti e servizi utilizza. Installare una skill non equivale a inviare automaticamente tutte le cartelle dei clienti. Vera non certifica il trattamento dei dati delle skill dello studio.
