Prima installazione

  1. Scarica il plugin che vuoi usare.

    Conserva il file .zip così com’è. Se il browser lo ha estratto automaticamente, recupera il file ZIP originale dai download.

  2. Apri i plugin in Claude.

    Nell’app Claude, apri Cowork, poi Personalizza (Customize) → Plugin (Plugins). Scegli Aggiungi (Add o +) → Carica plugin (Upload plugin).

  3. Carica lo ZIP.

    Seleziona il file appena scaricato, premi Upload e completa le richieste mostrate da Claude. Attendi che il plugin compaia nell’elenco dei tuoi plugin (Yours).

  4. Controlla il plugin e avvia una nuova attività.

    Apri la scheda di Vera, Clara o Lucia: controlla il nome, il numero di versione e che il plugin sia attivo (Enable plugin). Apri una nuova attività Cowork, seleziona la cartella di lavoro e descrivi cosa vuoi fare con il plugin.

Aggiornare una copia installata da ZIP

Per sostituire una vecchia copia personale con il pacchetto del sito, usa questa procedura. Non serve disinstallare l’app Claude.

  1. Scarica prima il nuovo ZIP da questa pagina e annota la versione attualmente mostrata nella scheda del plugin. Se hai personalizzato il plugin, conserva le modifiche che vuoi riapplicare prima di rimuoverlo.

  2. Rimuovi la vecchia copia del prodotto seguendo i passaggi qui sotto, poi carica il nuovo ZIP con la procedura di prima installazione.

  3. Verifica nella scheda il numero di versione della nuova copia e che sia attiva. Inizia una nuova attività Cowork per usare il plugin appena installato. Se la versione è ancora quella precedente, segnala il problema prima di continuare.

Rimuovere la vecchia versione del plugin

La rimozione riguarda Vera, Clara o Lucia nell’elenco dei plugin. Non eliminare l’app Claude, le cartelle di lavoro o i documenti dei clienti.

  1. Apri Personalizza (Customize) → Plugin (Plugins) → I tuoi (Yours) e individua il prodotto da sostituire.

  2. Apri il menu ⋯ accanto al nome e scegli Remove (Rimuovi). Puoi trovare lo stesso comando nel menu ⋯ della scheda del plugin.

  3. Se Claude chiede conferma, verifica il nome del plugin prima di confermare. Controlla che la vecchia copia sia scomparsa dall’elenco, poi installa il nuovo ZIP.

Turn off (Disattiva) spegne il plugin ma lo lascia nell’elenco. Per questa procedura di sostituzione usa Remove (Rimuovi).

Se un passaggio non compare

I nomi dei comandi possono variare con la lingua o la versione di Claude. Su un account gestito dallo studio, un plugin obbligatorio non può essere rimosso: chiedi all’amministratore. Se l’upload o la verifica non riescono, comunica nel gruppo prodotto, versione visualizzata, sistema operativo e testo completo dell’errore, senza documenti dei clienti.
