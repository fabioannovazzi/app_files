How to use this function

Prepare a financial report with Vera

Learn to turn accounting statements into a readable report with tables, commentary and references for checking the figures.

The explanation and a short practice take about 5–8 minutes. Processing and your questions can extend the session.

Start this course

  1. Open Codex on your computer with Vera installed and select @Vera in a chat.
  2. Copy the request below, paste it into the chat and send it.
  3. Turn on Codex voice in this chat. The assistant will guide you to open the second working chat in another window: listen and ask questions here, and watch the work and results there.

The fictional lesson files are already included in the plugin. You can also take the lesson in writing. This button copies the request; the lesson starts when you send it in Codex.

Two chats, one lesson

Speak with the teacher using the standard Codex voice. In the working chat, open in the window beside it, the function runs the case using the prepared files and shows its actual results. The teacher follows those results: interrupt, ask questions and change the pace whenever you need.

01

When to use it

Officina Arco supplies an income statement, balance sheet and cash-flow statement. The practice wants a first management report for the period.

One management report from available statements. This function organizes data and explanations into a document; sections without sources remain explicitly missing.

02

Files and request

Open january-february.xlsx and context-en.md. Look at the three sheets, period and currency. Tell Vera the audience, report type and language; you do not need to prepare slides or fill in technical configuration.

  • january-february.xlsx
  • context-en.md
Vera, prepare a management report for Officina Arco from the January and February statements. Help me review how you use the tables, then show me the Word document and points to review.
03

Run the workflow

  1. In the working chat, Vera inspects the sheets and proposes their report sections. Voice explains the structure and sources, helping you confirm company, period and amounts to report.
  2. Vera records the reviewed mapping, prepares source-supported commentary and runs the current workflow. Voice follows actual results and explains sections where information is missing.
  3. Open the Word document produced. Read the summary, a table and its commentary; trace a figure to its source sheet. Use report review to record corrections or clarification requests.
During the lesson, the working chat runs the function and produces the result. If a step is unavailable, explain what is missing and keep the lesson incomplete.
04

Use the result

  1. Word report and Markdown version with sections, tables and commentary.
  2. Table workbook and data references for checking the document.

Check period, currency, sheet assignments and fidelity of commentary. Do not count subtotals twice. Distinguish supported and missing sections and review the text before professional use.

05

Pause and check

  1. Before generation, identify the information that will enter the report.
  2. In Word, find a figure and its source statement, then a point needing review.

These pauses help you learn how to use the function. They are not a technical detail quiz.

06

Try it yourself

Repeat with january-march.xlsx and request a new report through March, preserving the earlier one. Check that period, tables and commentary are updated; choose a correction to propose.
  • january-march.xlsx
  • context-en.md

You can supply statements, request the report, open the document, verify a source and repeat the task for a new period.

Give Vera the client statements and specify period, audience, language and report type. Review structure, amounts and commentary, then use the document in the normal approval process.

The kit contains fictional files and a prepared outline. Demonstration and practice results come from fresh runs of the current function.
