How to use this function

Find a client’s documents with Vera

Learn to connect a studio folder, search the right client and obtain an answer linked to its source documents.

The explanation and a short practice take about 5–8 minutes. Processing and your questions can extend the session.

Start this course

  1. Open Codex on your computer with Vera installed and select @Vera in a chat.
  2. Copy the request below, paste it into the chat and send it.
  3. Turn on Codex voice in this chat. The assistant will guide you to open the second working chat in another window: listen and ask questions here, and watch the work and results there.

The fictional lesson files are already included in the plugin. You can also take the lesson in writing. This button copies the request; the lesson starts when you send it in Codex.

Two chats, one lesson

Speak with the teacher using the standard Codex voice. In the working chat, open in the window beside it, the function runs the case using the prepared files and shows its actual results. The teacher follows those results: interrupt, ask questions and change the pace whenever you need.

01

When to use it

The studio wants to find Ciclo Arco’s agreed maintenance service and the end date stated in its agreement. The fictional archive also contains another client.

Local document search. Gmail, WhatsApp and Google Drive are separate routes requiring their own connections; this lesson does not activate them.

02

Files and request

Open archive: it contains Ciclo Arco and Delta, each with its own agreement. Vera prepares a teaching copy and separate local index while retaining your existing studio archive settings.

  • maintenance-en.md
  • maintenance-en.md
Vera, find Ciclo Arco’s agreement with Tecnica Esempio. What service is provided and until when? Show the passages supporting your answer.
03

Run the workflow

  1. In the working chat, Vera prepares the teaching folder, checks access and indexes readable documents. If a folder selection is needed, choose the exercise folder.
  2. Select Ciclo Arco. The current workflow searches within that client and opens relevant sources; the voice chat explains the move from a search result to its document.
  3. Read the answer and open its citations. Check the client, monthly service and stated period. Locate any extraction limits or documents that were not indexed.
During the lesson, the working chat runs the function and produces the result. If a step is unavailable, explain what is missing and keep the lesson incomplete.
04

Use the result

  1. Answer with source links: service, period and the document passages describing them.
  2. Index status and search trail: selected client, opened sources and encountered limits.

Check the selected client and read the cited passage. Search finds content in indexed files; it does not prove that all agreements are present or that a document is legally valid.

05

Pause and check

  1. Before searching, identify Ciclo Arco’s folder.
  2. At delivery, open a citation and find the stated fact in its document.

These pauses help you learn how to use the function. They are not a technical detail quiz.

06

Try it yourself

Add update-en.md from the practice files to the Ciclo Arco teaching copy, keep the agreement and ask Vera to refresh the index. Repeat the end-date question and open both sources.
