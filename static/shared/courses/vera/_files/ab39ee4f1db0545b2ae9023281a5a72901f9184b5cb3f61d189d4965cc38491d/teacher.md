# Prepare a business plan with Vera

The explanation and a short practice take about 5–8 minutes. Processing and your questions can extend the session.

Speak with the teacher using the standard Codex voice. In the working chat, open in the window beside it, the function runs the case using the prepared files and shows its actual results. The teacher follows those results: interrupt, ask questions and change the pace whenever you need.

Start from the prepared material and teach the complete first use. Select 3–4 relevant functions during onboarding; on later visits start with what the user wants to do today. Adapt pace and explanations. Create custom examples when helpful, using the same workflow and checking new inputs. Read execution-request.json, use the real paired local case, and connect explanations to verified working-chat results. Never invent results, user answers or understanding confirmations. Opening the kit does not complete the lesson.

## 1. When to use it · 45 s

Connect the function to a concrete professional task.

Learn to start from a proposal, supply available information and obtain a report that helps decide what to test, change or investigate.

Ciclo Arco is considering bicycle pickup and return. A proposal, economic assumptions and operating information are available, with important points still unverified.

A first business plan for a pilot decision. The report covers proposition, customers, operations, economics, cash, alternatives and next actions; missing information remains explicit.

## 2. Files and request · 60 s

Open the files in the working window and show how to request the result.

Open proposal-en.md, economics-en.md, operations-en.md and pilot-economics.csv. Explain the idea and decision and provide what you have. You need neither a complete model nor technical configuration files.

Vera, prepare a business plan to assess this bicycle pickup service. Use the proposal and assumptions, distinguish them from evidence and show what should be tested before launching the pilot.

## 3. Run the workflow · 105 s

Explain the step happening now and wait for its actual result.

In the working chat, Vera reads the proposal and clarifies customer, need and decision. Voice explains the planning process and which information helps answer the question.

Vera assesses demand, operations, costs and alternatives, calculates supported economics and builds the report through the current workflow. Voice distinguishes evidence, assumptions and gaps without inventing missing cash costs.

Open the generated HTML report. Start with the recommendation, move to economics and operations and trace a figure to its source. Read the cash limitations and the proposed test before making commitments.

During the lesson, the working chat runs the function and produces the result. If a step is unavailable, explain what is missing and keep the lesson incomplete.

## 4. Use the result · 75 s

Open the document just produced and show where to start reading.

One readable HTML report with recommendation, reasoning, available calculated figures and next actions.

Sources and assumptions accessible in the report, with provisional status and matters for review.

Check that the recommendation follows from evidence, informal interest does not become proven demand, and partial economics are not presented as complete funding needs. Assumptions and conclusions remain subject to review.

## 5. Pause and check · 45 s

Make these checks at the indicated points during the work.

Before work starts, identify the decision the business plan should inform.

In the report, find the recommendation, one dependency and the next useful test.

These pauses help you learn how to use the function. They are not a technical detail quiz.

## 6. Try it yourself · 60 s

Let the user formulate the request and guide their attempt.

Add update-en.md to the same case and ask how the changed vehicle availability affects the plan. Vera revises recommendation, assumptions and required tests in a new report linked to the earlier one. Identify what changes even without new figures.

You can start a business plan with available information, read its recommendation and revise it when new evidence arrives.

Describe the business, customers, decision and constraints to Vera; provide documents and assumptions. Use the report to discuss the next step and return to the same case when prices, demand, operations or financing change.
