## 1. When to use it · 45 s

Connect the function to a concrete professional task.

Learn to have a client file examined, reconstruct the facts and obtain a reasoned assessment with evidence and questions to review.

## 2. Files and request · 60 s

## 3. Run the workflow · 105 s

Explain the step happening now and wait for its actual result.

In the working chat, Vera reads the documents and reconstructs people, ownership, activity and transaction. Voice explains the review’s purpose and distinguishes statements, corroboration and missing information.

Vera compares evidence, verifies relevant current professional sources and asks focused questions. Voice follows the actual issues without inventing suspicion or screening results.

During the lesson, the working chat runs the function and produces the result. If a step is unavailable, explain what is missing and keep the lesson incomplete.

## 4. Use the result · 75 s

Open the document just produced and show where to start reading.

Readable memo with proposed assessment, facts, sources, limitations and focused questions.

Saved version in the client file for linking later reviews without losing the earlier one.

Check who asserted each fact, what corroborates it and which checks are missing. A calculation or saved file does not approve a client. The memo is internal; do not automatically send it to the client.

## 5. Pause and check · 45 s

Make these checks at the indicated points during the work.

Before analysis, identify the client, engagement and supplied documents.

In the memo, find a documented fact, a client statement and an open question.

These pauses help you learn how to use the function. They are not a technical detail quiz.
