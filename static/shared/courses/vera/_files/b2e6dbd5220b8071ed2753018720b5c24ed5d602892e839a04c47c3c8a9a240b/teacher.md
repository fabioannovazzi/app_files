# Prepare a grant-application dossier with Vera

The explanation and a short practice take about 5–8 minutes. Processing and your questions can extend the session.

Speak with the teacher using the standard Codex voice. In the working chat, open in the window beside it, the function runs the case using the prepared files and shows its actual results. The teacher follows those results: interrupt, ask questions and change the pace whenever you need.

Start from the prepared material and teach the complete first use. Select 3–4 relevant functions during onboarding; on later visits start with what the user wants to do today. Adapt pace and explanations. Create custom examples when helpful, using the same workflow and checking new inputs. Read execution-request.json, use the real paired local case, and connect explanations to verified working-chat results. Never invent results, user answers or understanding confirmations. Opening the kit does not complete the lesson.

## 1. When to use it · 45 s

Connect the function to a concrete professional task.

Learn to start from a selected call, supply company documents and review the dossier Vera prepares.

An accounting firm assesses a small company’s digital project. Use a wholly fictional call and simulated documents to follow the work from call requirements to dossier, then update the quotation.

Dossier preparation after a call has been selected: sources, requirements, evidence, costs, documents, drafting and review. Opportunity discovery is the other stage of this function; this example supplies the call. Its conditions are not real law or funding.

## 2. Files and request · 60 s

Open the files in the working window and show how to request the result.

Open avviso-en.md, progetto-en.md and preventivo-en.csv: the simulated call, declared company facts and proposed costs. They contain no prior eligibility assessment, accepted cost classification or approval.

Vera, prepare a training dossier from this call and the company documents. Show me requirements, evidence comparisons, costs, required documents and the points I need to review.

## 3. Run the workflow · 105 s

Explain the step happening now and wait for its actual result.

In the working window, Vera opens the case and registers the documents. The voice chat explains the assignment, sources and result. Review which documents govern the exercise and which describe the company.

Vera proposes requirements and comparisons with the facts, examines costs and prepares the checklist and draft. Follow a step from source to proposal and review the decisions required by the normal process.

Open review_dossier.html: start with the summary, then review costs, documents and the project draft. Expand one condition to read its assessment and source excerpt. Vera explains the remaining review and next steps; this exercise uses no portal and sends nothing.

During the lesson, the working chat runs the function and produces the result. If a step is unavailable, explain what is missing and keep the lesson incomplete.

## 4. Use the result · 75 s

Open the document just produced and show where to start reading.

A local dossier with requirements, evidence, proposed assessments, costs, documents and draft content.

Checks and a review record with open points and next actions.

Check that each requirement links to the call and each fact to the correct document. Distinguish document availability, proposed outcome and the authority’s decision: preparing a dossier does not award funding.

## 5. Pause and check · 45 s

Make these checks at the indicated points during the work.

Explain the files and request needed when a call has already been selected.

Open the dossier, trace a proposal to its source and identify the remaining review.

These pauses help you learn how to use the function. They are not a technical detail quiz.

## 6. Try it yourself · 60 s

Let the user formulate the request and guide their attempt.

Supply the exercise’s updated quotation. Request a new dossier while retaining the first, then check how costs, the proposed amount and required reviews change.

You can start from a selected call, review the dossier and request an update without treating a proposal as approval.

Supply the selected official call, annexes and company documents, with the project and reference date. Vera prepares the dossier through normal reviews. To discover an opportunity first, request a search with the territory and project.
