# Officina Arco

Cas fictif Officina Arco, mars 2026, EUR. Le journal contient 9 lignes pour 3 factures d’achat. Date = date comptable, Entry = écriture, Line = ligne, Account = compte, Description = libellé, Debit/Credit = débit/crédit, Document = référence de facture. Montants avec point décimal sans séparateur de milliers. Entry et Line identifient la ligne ; aucun report. Le compte 2100 contient les 3 dettes fournisseur, une par facture ; les autres lignes sont charge et TVA. Totaux débit et crédit : 2440.00 chacun. Démonstration : sélectionner avec Journal Sampling 2 lignes aléatoires du compte 2100, graine 42. Pratique : produire un nouvel échantillon de 3 lignes du même compte. Les trois factures XML sont fictives, noms et identifiants compris ; ne jamais les transmettre à SdI. Échantillon et résultats sont produits pendant la leçon ; aucune conclusion professionnelle n’est déjà approuvée.
