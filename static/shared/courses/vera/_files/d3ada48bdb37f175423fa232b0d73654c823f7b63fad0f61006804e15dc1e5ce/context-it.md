# Officina Arco

Caso fittizio Officina Arco, marzo 2026, EUR. Il giornale contiene 9 righe di 3 fatture di acquisto. Date = data, Entry = registrazione, Line = riga, Account = conto, Description = descrizione, Debit/Credit = dare/avere, Document = riferimento fattura. Gli importi hanno punto decimale senza raggruppamento. Entry e Line identificano la riga; nessun riporto. Il conto 2100 contiene le 3 righe di debito verso fornitore, una per fattura. Le altre righe sono costo e IVA. Totali dare e avere: 2440.00 ciascuno. Per la dimostrazione, prepara con Journal Sampling un campione casuale di 2 righe del conto 2100, seme 42. Per la pratica, prepara un nuovo campione di 3 righe dello stesso conto. Le tre fatture XML sono tutte fittizie, con nomi e identificativi segnaposto. Non inviarle a SdI. Il campione e i risultati della verifica devono essere prodotti durante la lezione; nessuna conclusione professionale è già approvata.
