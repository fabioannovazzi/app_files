## 1. When to use it · 45 s

Connect the function to a concrete professional task.

Learn to obtain an organisation plan, review destinations and apply approved changes to a folder.

Ciclo Arco’s folder contains an agreement, an exact copy and an internal meeting note in two intake folders. We will prepare a readable plan and try it on a teaching copy.

One client and fictional local files. Applying changes requires an explicit choice; the lesson does not change the real studio archive.

## 2. Files and request · 60 s

Open the files in the working window and show how to request the result.

Open client and inspect Da archiviare and Download. Read the agreement and meeting note. Vera copies them into a separate teaching client and uses the workflow’s studio folder policy. Default folder labels are Italian.

Vera, propose how to organise this Ciclo Arco folder. Show documents, destinations and duplicate copies before moving anything.

## 3. Run the workflow · 105 s

Explain the step happening now and wait for its actual result.

The working chat creates the teaching client and captures its file snapshot. Vera reads the necessary evidence and proposes categories and destinations from the contents.

Open the generated review page. Inspect every proposal, keep or edit the destination and decide how to handle the exact copy. The plan remains proposed until reviewed.

After those decisions, Vera summarises planned moves and separately asks whether to apply them. If you approve the teaching-copy changes, it executes the plan and shows the resulting folders and operation journal.

During the lesson, the working chat runs the function and produces the result. If a step is unavailable, explain what is missing and keep the lesson incomplete.

## 4. Use the result · 75 s

Open the document just produced and show where to start reading.

Review page and plan: starting files, proposed destinations, reasons and saved decisions.

After authorized application: organised folder and journal for checking moves and considering rollback.

Follow a document from its original location to its destination. The exact copy is retained in the duplicate-review area rather than deleted. Reviewing a proposal is separate from authorizing file moves.

## 5. Pause and check · 45 s

Make these checks at the indicated points during the work.

Before the plan, identify the client and teaching folder.

Before application, explain one chosen destination and check the planned moves.

These pauses help you learn how to use the function. They are not a technical detail quiz.
