# Teach Vera your studio’s document format

The explanation and a short practice take about 5–8 minutes. Processing and your questions can extend the session.

Speak with the teacher using the standard Codex voice. In the working chat, open in the window beside it, the function runs the case using the prepared files and shows its actual results. The teacher follows those results: interrupt, ask questions and change the pace whenever you need.

Start from the prepared material and teach the complete first use. Select 3–4 relevant functions during onboarding; on later visits start with what the user wants to do today. Adapt pace and explanations. Create custom examples when helpful, using the same workflow and checking new inputs. Read execution-request.json, use the real paired local case, and connect explanations to verified working-chat results. Never invent results, user answers or understanding confirmations. Opening the kit does not complete the lesson.

## 1. When to use it · 45 s

Connect the function to a concrete professional task.

Learn to turn selected examples into a reviewed, reusable Word report standard.

Fictional Studio Riva wants its reports to use a consistent font, margins, header, tables and footer.

Word formatting for the financial report builder. This is private configuration, not model training or exact template cloning. Other document generators remain outside this first integration.

## 2. Files and request · 60 s

Open the files in the working window and show how to request the result.

Open demo-en.json. Vera uses it to generate a real fictional Word example and accounting CSV locally. Select the studio workspace and review the example; no client documents are needed.

Vera, learn this fictional studio’s report format. Show what you observed, propose the missing settings, let me review short and long previews, then save the version I approve and use it in a financial report.

## 3. Run the workflow · 105 s

Explain the step happening now and wait for its actual result.

Generate and inspect the real example. Distinguish observed settings from proposals and uncertain inherited styling. Choose one change in ordinary language.

Generate the short and long Word previews. Open their actual pages, check fonts, table continuation and footer, then decide whether to correct or explicitly adopt the exact version.

After adoption, produce a small financial Word report from the CSV through the current report procedure and its real synthetic client run. Check the saved studio identity and trace an unchanged amount to its source.

During the lesson, the working chat runs the function and produces the result. If a step is unavailable, explain what is missing and keep the lesson incomplete.

## 4. Use the result · 75 s

Open the document just produced and show where to start reading.

Selected-example formatting evidence and a complete proposal.

Short and long synthetic Word previews, a versioned approved standard and a financial report using it.

Review all preview pages, substitutions, logo if selected, dates, number display and the saved studio identity. Figures and conclusions remain subject to the report’s normal review. No script proves that you saw or accepted the document.

## 5. Pause and check · 45 s

Make these checks at the indicated points during the work.

Explain which setting came from the example and which you chose.

Before saving, open both previews and explicitly approve or request a correction.

These pauses help you learn how to use the function. They are not a technical detail quiz.

## 6. Try it yourself · 60 s

Let the user formulate the request and guide their attempt.

Start independently with practice-en.json for fictional Studio Selva and different amounts. Choose a change, review and adopt its own standard, then generate its report. Revise one setting once more, review fresh previews and verify the previous version remains archived. Check that Studio Riva is unchanged.

You can supply examples, correct the proposal, review and adopt an exact version, find it again, reuse it and revise it without changing another studio or financial data.
