# Fiktive Beitragsübersicht

contribution-periods-de.csv ist eine vereinfachte erfundene Übersicht für den Unterricht zum Zeitraum 2025-01-01–2025-06-30, datiert auf 2026-08-01. Die aufgeführten Zeilen bilden die gesamte Lehrübersicht. Sie ist kein offizieller INPS-Download und darf nicht als solcher registriert werden. Ein fehlender Zeitraum beweist keine Nichtzahlung. In der Übung ersetzt die Übersicht vom 2026-09-01 die frühere, ohne Zeitpunkt oder Ursache der Datenänderung zu belegen.
