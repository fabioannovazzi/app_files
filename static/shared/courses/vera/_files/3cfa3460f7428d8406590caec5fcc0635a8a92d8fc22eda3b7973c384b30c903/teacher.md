## 4. Use the result · 75 s

Open the document just produced and show where to start reading.

Word report and Markdown version with sections, tables and commentary.

Table workbook and data references for checking the document.

Check period, currency, sheet assignments and fidelity of commentary. Do not count subtotals twice. Distinguish supported and missing sections and review the text before professional use.

## 5. Pause and check · 45 s
