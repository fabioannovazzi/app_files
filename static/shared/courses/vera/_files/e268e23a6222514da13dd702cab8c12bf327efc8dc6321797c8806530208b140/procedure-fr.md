# Procédure mensuelle

Procédure interne fictive adoptée le 5 janvier 2026. Sara transmet les documents mensuels avant le dix du mois suivant ; le cabinet retourne la synthèse avant le vingt. Elena la revoit sous cinq jours et note les décisions. Chaque lundi Sara prépare l’échéancier clients et Elena décide des relances. Aucun remplaçant de Sara n’est indiqué. Le texte décrit le fonctionnement prévu, sans prouver son application chaque mois.
