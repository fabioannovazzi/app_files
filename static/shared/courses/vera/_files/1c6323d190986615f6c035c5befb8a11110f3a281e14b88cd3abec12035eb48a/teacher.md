## 4. Use the result · 75 s

Missing-information request, document plan and monitoring plan: identify subsequent work and matters still requiring confirmation.

## 5. Pause and check · 45 s

Before starting, identify the client and requested services.

At delivery, find a source, a document to obtain and a decision still needed.

These pauses help you learn how to use the function. They are not a technical detail quiz.
