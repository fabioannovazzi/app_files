# Officina Arco

Caso ficticio Officina Arco, marzo de 2026, EUR. El diario contiene 9 líneas de 3 facturas de compra. Date = fecha contable, Entry = asiento, Line = línea, Account = cuenta, Description = descripción, Debit/Credit = debe/haber, Document = referencia de factura. Importes con punto decimal sin separadores de miles. Entry y Line identifican cada línea; sin arrastre. La cuenta 2100 contiene las 3 deudas con proveedor, una por factura; las otras líneas son gasto e IVA. Totales debe y haber: 2440.00 cada uno. Demostración: seleccionar mediante Journal Sampling 2 líneas aleatorias de la cuenta 2100, semilla 42. Práctica: generar otra muestra de 3 líneas de la misma cuenta. Las tres facturas XML son ficticias, con nombres e identificadores de ejemplo; no enviarlas a SdI. Muestra y resultados se producen durante la lección; no existe una conclusión profesional aprobada.
