# Officina Arco

Caso fittizio Officina Arco, EUR. Il giornale di marzo contiene 13 righe per 3 fatture e 2 pagamenti; quello cumulativo di aprile 15 righe, con un pagamento aggiuntivo. Date = data, Entry = identificativo della registrazione, Line = riga della registrazione, Account = conto, Description = descrizione, Debit/Credit = dare/avere, Document = riferimento documento, Reference = riferimento pagamento. Importi in euro, punto decimale, nessun raggruppamento. Entry e Line identificano la riga; gli identificativi non sono importi. Nessun riporto da righe precedenti. Totali dare e avere: marzo 4392.00 ciascuno; marzo–aprile 4880.00 ciascuno. L’esercizio usa un campione casuale di 5 righe, seme 42, sull’intero file di marzo. La pratica ripete sul file marzo–aprile. Sono scelte didattiche, non una valutazione di adeguatezza del campione per una revisione reale.
