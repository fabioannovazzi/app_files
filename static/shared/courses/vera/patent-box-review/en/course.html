01

When to use it

Arco Software is fictional. Its Faro project is an original module used internally in 2025; the ledger separates development personnel from ordinary maintenance.

Controlled Italian preview: ordinary software first use. Conversation is in English; engine documents retain Italian titles and fields. Patents, designs and the premial branch need different evidence and are not demonstrated. All 32 professional UAT scenarios remain NOT_RUN; professional and installed-host acceptance is unverified.

02

Files and request

Open evidence-en.md, ledger-demo.csv and synthetic-rules.txt. Identify rights, activities, period, project, ledger rows and proposed income/IRAP bases. Facts are invented and fiscal bases are teaching assumptions. The synthetic source is only for the historical test date 23 September 2026, not current law.

  • evidence-en.md
  • ledger-demo.csv
  • synthetic-rules.txt
Vera, prepare a fictional Patent Box dossier for Faro using these files. Show evidence, reconciliation, proposed controls and open questions; after my confirmation run only the synthetic calculation and show the draft A/B dossier.
03

Run the workflow

  1. Vera imports only these files into a separate local tutorial case, reads them and proposes scope. The voice teacher links software, rights, activities and use to note sections; explain what evidence a patent or design would need without inventing it.
  2. Vera inspects the CSV rows and proposes mapping, book total and separate bases. Review maintenance exclusion, cost-to-project links, the declared absence of other incentives and the limits of declarations. No mapping or approval is supplied.
  3. Open the readable proposal review. Only after actual confirmation of its exact version record a synthetic review and execute the engine with demo and synthetic rules at the historical date. The tutorial configures no real mandate or sources. Open the actual summary, reconciliation and Word/PDF dossier, then the model-data report.
During the lesson, the working chat runs the function and produces the result. If a step is unavailable, explain what is missing and keep the lesson incomplete.
04

Use the result

  1. Case summary, missing documents, control matrix and cost reconciliation with rows and sources.
  2. Workpaper, unsigned Word/PDF A/B dossier, calculation record and model-data report.

Start with the summary and trace an amount to its ledger row. Additional deduction is not a tax saving: the engine does not calculate savings. A suspended control does not prove ineligibility. The dossier remains a draft: no sending, signing, filing or penalty protection. Real cases require current reviewed sources/rules and authenticated professional authorization; teaching confirmation cannot replace them.

05

Pause and check

  1. Before calculation link a row to a project and activity and explain why the bases may differ.
  2. Find an excluded cost, its reason and source in the draft. Consider whether the evidence would suffice for a real client.

These pauses help you learn how to use the function. They are not a technical detail quiz.

06

Try it yourself

Request a fresh case using evidence-practice-en.md, ledger-practice.csv and the same synthetic source. The ledger adds personnel cost without a documented project link. Do not invent it: review the proposal, preserve demonstration outputs and find the suspended cost and document request in the new draft.
  • evidence-practice-en.md
  • ledger-practice.csv
  • synthetic-rules.txt

You can select files, make the request, reconcile an amount, explain exclusion versus suspension and identify outstanding professional checks.

For real work specify company, period, asset and purpose; supply rights, activities, costs and incentive history. Review mapping and controls with the professional and follow normal authorization. Never reuse synthetic sources, approval or date.
