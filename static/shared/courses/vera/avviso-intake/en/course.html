How to use this function

Prepare a first reading of a tax notice with Vera

Learn to supply a tax communication and obtain an operational note with references, missing information and checks to perform.

The explanation and a short practice take about 5–8 minutes. Processing and your questions can extend the session.

Two chats, one lesson

Speak with the teacher using the standard Codex voice. In the working chat, open in the window beside it, the function runs the case using the prepared files and shows its actual results. The teacher follows those results: interrupt, ask questions and change the pace whenever you need.

01

When to use it

Marco Prova brings the practice a request for documents. We need to understand what it says, what to collect and which dates to verify before deciding how to proceed.

Fictional Italian case. First intake organizes document facts; legal assessment and a response follow the normal professional process.

02

Files and request

Open avviso.md, an Italian teaching transcription of communication DEMO-NOTICE-01. It states the addressee, period, requested documents and a response date; evidence of receipt is missing.

  • avviso.md
Vera, prepare a first-intake note for Marco Prova’s communication. Summarize the request, references, dates to verify and documents to collect.
03

Run the workflow

  1. Vera imports the communication into the teaching case and runs reading and extraction. Check that the text is readable and its classification fits the contents.
  2. The workflow prepares the intake note and reference list. The voice chat explains which elements come from the letter and which information remains missing.
  3. Open the results and compare them with the communication. Locate the document request, reference number, stated dates and next checks.
During the lesson, the working chat runs the function and produces the result. If a step is unavailable, explain what is missing and keep the lesson incomplete.
04

Use the result

  1. First-intake note: helps the practice understand the request and organize document collection.
  2. Dates, amounts and references table: helps locate source evidence; a detected date is not automatically a verified legal deadline.

Verify reference number, period and request against the text. The letter does not quantify a debt. Distinguish its stated response date from the missing evidence of receipt.

05

Pause and check

  1. Before starting, identify the communication and the purpose of the intake.
  2. At delivery, show what is requested and what is needed before a response.

These pauses help you learn how to use the function. They are not a technical detail quiz.

06

Try it yourself

Add client-update.md and request a new note. The client reports when he found the communication and which documents he recovered; the practice has not yet received them.
  • avviso.md
  • client-update.md

The updated note distinguishes the client’s statement from evidence of receipt and keeps outstanding documents visible.

Supply the full communication and available receipt evidence, request first intake and check the note before deciding on a response and further analysis.
