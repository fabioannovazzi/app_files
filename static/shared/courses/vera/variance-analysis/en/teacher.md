## 1. When to use it · 45 s

Connect the function to a concrete professional task.

Learn which data to provide, how to start the comparison and how to read a report showing the size and location of differences from budget.

Officina Arco wants to compare January and February operating profit with budget. It has monthly revenue and cost data and a note explaining the figures.

First use of variance analysis: one company, two months, EUR. We compare amounts; the file contains no quantities or evidence of commercial causes.

## 2. Files and request · 60 s

Open the files in the working window and show how to request the result.

Open january-february.csv and context-en.md. Find Scenario (PL budget, AC actual), Month, Category and Amount. The note explains signs and control totals. Vera stages a copy in the teaching case.

Vera, compare Officina Arco’s actual operating profit for January and February 2026 with budget, in euros. Show me the report and explain which categories contribute to the difference.

## 3. Run the workflow · 105 s

Explain the step happening now and wait for its actual result.

In the working chat, Vera reads the file and proposes the comparison. The voice chat helps you check months, starting budget, actual results, currency and negative cost signs before calculation.

The current workflow calculates variances and creates tables, charts and a report draft. While it runs, the voice explains the process and answers questions without anticipating results that have not been produced.

Open the actual report and main chart. Start with the overall result, then read revenue and cost contributions and one monthly detail. Vera connects each comment to calculated data and saves actual review decisions.

During the lesson, the working chat runs the function and produces the result. If a step is unavailable, explain what is missing and keep the lesson incomplete.

## 4. Use the result · 75 s

Open the document just produced and show where to start reading.

Word report draft and charts showing the movement from budget to actual.

Variance tables and reconciliation controls for tracing amounts to their sources.

Check scope and months, starting and ending totals, change in EUR and percentage where meaningful. Read the meaning of negative cost signs. Calculation identifies contributions but does not itself prove commercial causes. The report remains a draft until normal professional review.

## 5. Pause and check · 45 s

Make these checks at the indicated points during the work.

Before calculation, identify the values being compared.

In the result, find one contributing category and its supporting figure.

These pauses help you learn how to use the function. They are not a technical detail quiz.

## 6. Try it yourself · 60 s

Let the user formulate the request and guide their attempt.

Use january-march.csv to repeat the comparison for January through March. Request a new result while keeping the two-month version. Identify the change in the total and one category; ask for help only where needed.

You can choose the file and comparison, find the report, read a variance and repeat the analysis when another month arrives.
