How to use this function

Compare actual results with budget using Vera

Learn which data to provide, how to start the comparison and how to read a report showing the size and location of differences from budget.

The explanation and a short practice take about 5–8 minutes. Processing and your questions can extend the session.

Two chats, one lesson

Speak with the teacher using the standard Codex voice. In the working chat, open in the window beside it, the function runs the case using the prepared files and shows its actual results. The teacher follows those results: interrupt, ask questions and change the pace whenever you need.

01

When to use it

Officina Arco wants to compare January and February operating profit with budget. It has monthly revenue and cost data and a note explaining the figures.

First use of variance analysis: one company, two months, EUR. We compare amounts; the file contains no quantities or evidence of commercial causes.

02

Files and request

Open january-february.csv and context-en.md. Find Scenario (PL budget, AC actual), Month, Category and Amount. The note explains signs and control totals. Vera stages a copy in the teaching case.

  • january-february.csv
  • context-en.md
Vera, compare Officina Arco’s actual operating profit for January and February 2026 with budget, in euros. Show me the report and explain which categories contribute to the difference.
03

Run the workflow

  1. In the working chat, Vera reads the file and proposes the comparison. The voice chat helps you check months, starting budget, actual results, currency and negative cost signs before calculation.
  2. The current workflow calculates variances and creates tables, charts and a report draft. While it runs, the voice explains the process and answers questions without anticipating results that have not been produced.
  3. Open the actual report and main chart. Start with the overall result, then read revenue and cost contributions and one monthly detail. Vera connects each comment to calculated data and saves actual review decisions.
During the lesson, the working chat runs the function and produces the result. If a step is unavailable, explain what is missing and keep the lesson incomplete.
04

Use the result

  1. Word report draft and charts showing the movement from budget to actual.
  2. Variance tables and reconciliation controls for tracing amounts to their sources.

Check scope and months, starting and ending totals, change in EUR and percentage where meaningful. Read the meaning of negative cost signs. Calculation identifies contributions but does not itself prove commercial causes. The report remains a draft until normal professional review.

05

Pause and check

  1. Before calculation, identify the values being compared.
  2. In the result, find one contributing category and its supporting figure.

These pauses help you learn how to use the function. They are not a technical detail quiz.

06

Try it yourself

Use january-march.csv to repeat the comparison for January through March. Request a new result while keeping the two-month version. Identify the change in the total and one category; ask for help only where needed.
  • january-march.csv
  • context-en.md

You can choose the file and comparison, find the report, read a variance and repeat the analysis when another month arrives.

With your own file, state company, period, budget or other comparison basis and currency. Vera clarifies ambiguous columns, produces the results and guides your review.

The kit contains fictional files and a prepared outline. Demonstration and practice results come from fresh runs of the current function.
