# Officina Arco

Caso interamente fittizio: Officina Arco, una sola impresa, nessun consolidamento. Confronto dei risultati operativi effettivi (AC) con il budget (PL), negli stessi mesi del 2026. Valuta EUR, nessuna conversione. Amount contiene ricavi positivi e costi negativi: Revenue = ricavi, COGS = costo del venduto, Operating expenses = spese operative. Un aumento del risultato operativo è favorevole. Month indica il mese; Category la voce del conto economico. Non sono disponibili quantità, prezzi unitari o prove delle cause commerciali. Non applicare una soglia di materialità in questo esempio; conservare tutte le voci.
