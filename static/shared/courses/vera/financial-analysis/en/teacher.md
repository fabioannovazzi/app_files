# Prepare financial analysis with Vera

The explanation and a short practice take about 5–8 minutes. Processing and your questions can extend the session.

Speak with the teacher using the standard Codex voice. In the working chat, open in the window beside it, the function runs the case using the prepared files and shows its actual results. The teacher follows those results: interrupt, ask questions and change the pace whenever you need.

Start from the prepared material and teach the complete first use. Select 3–4 relevant functions during onboarding; on later visits start with what the user wants to do today. Adapt pace and explanations. Create custom examples when helpful, using the same workflow and checking new inputs. Read execution-request.json, use the real paired local case, and connect explanations to verified working-chat results. Never invent results, user answers or understanding confirmations. Opening the kit does not complete the lesson.

## 1. When to use it · 45 s

Connect the function to a concrete professional task.

Learn to request a specific analysis, provide the data, review the choices and use financial results you can check.

Officina Arco wants its net debt at the end of February. Its statement lists a loan, available cash and two other items to classify.

Financial Analysis prepares accounting analyses and due-diligence calculations from reviewed inputs. This complete first run calculates net debt at one date; other analyses need their own inputs and decisions.

## 2. Files and request · 60 s

Open the files in the working window and show how to request the result.

Open balances-february.csv and context-en.md. State company, date, EUR and the requested definition. The note explains the balances; Vera prepares technical structures after review, without asking you to program them.

Vera, prepare Officina Arco’s net-debt analysis at 28 February using this statement and the definition in the note. Guide me through the choices and show the result, detail and controls.

## 3. Run the workflow · 105 s

Explain the step happening now and wait for its actual result.

In the working chat, Vera identifies the relevant analysis and proposes item classifications. Voice explains what is measured and helps you review amounts, date, inclusions and exclusions.

After the actual review, Vera records choices and runs the current calculation. Voice follows execution and distinguishes an arithmetic check from completeness of the supplied data.

Read the delivery summary and open the generated detail. Trace loan and cash to source rows, then find excluded items, calculation controls and questions still open.

During the lesson, the working chat runs the function and produces the result. If a step is unavailable, explain what is missing and keep the lesson incomplete.

## 4. Use the result · 75 s

Open the document just produced and show where to start reading.

Analysis result and included/excluded line items presented in the delivery.

Data package, controls and references to choices and sources for professional review.

Check that the definition matches the request and all balances have the same date. Reproducible arithmetic alone does not establish completeness or accounting correctness. Review sources and conclusions before using the result.

## 5. Pause and check · 45 s

Make these checks at the indicated points during the work.

Before calculation, explain what you want to measure and which inputs it needs.

In the result, identify an included balance, an excluded balance and their reasons.

These pauses help you learn how to use the function. They are not a technical detail quiz.

## 6. Try it yourself · 60 s

Let the user formulate the request and guide their attempt.

Use balances-march.csv for a new analysis at 31 March with the same definition. Preserve February and identify which balances and result change.

You can select the analysis, supply the statement, review choices, find the result and detail and update the work to a new date.

Describe the financial question, company, date or period and available data to Vera. Review the proposed analysis and substantive choices, then check the generated package before professional use.
