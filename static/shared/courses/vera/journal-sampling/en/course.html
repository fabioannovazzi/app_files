How to use this function

Select a sample from an accounting journal

Learn to provide a journal, check how it is read and obtain selected rows for subsequent examination.

The explanation and a short practice take about 5–8 minutes. Processing and your questions can extend the session.

Two chats, one lesson

Speak with the teacher using the standard Codex voice. In the working chat, open in the window beside it, the function runs the case using the prepared files and shows its actual results. The teacher follows those results: interrupt, ask questions and change the pace whenever you need.

01

When to use it

The practice needs to select some Officina Arco journal rows for review. A small fictional file lets us follow every step.

First Journal Sampling run: 5 random rows, seed 42. This teaches operation; the real audit plan determines method and sample size.

02

Files and request

Open journal-march.csv and context-en.md. Find date, posting, line, account, debit and credit. The original remains preserved in the teaching case.

  • journal-march.csv
  • context-en.md
Vera, select 5 random rows from Officina Arco’s March journal using seed 42. First let me check the columns, then show me the sample and journal preparation checks.
03

Run the workflow

  1. Vera opens the journal in the working chat. Voice guides you through columns, period and amount meanings; Vera records the mapping actually reviewed.
  2. The workflow prepares the journal and checks that rows and amounts are preserved. If preparation fails, resolve the issue before selecting a sample.
  3. Vera runs the sampling and opens the Excel result. Find one selected row and trace it to the journal; review population size, method and number of sampled rows together.
During the lesson, the working chat runs the function and produces the result. If a step is unavailable, explain what is missing and keep the lesson incomplete.
04

Use the result

  1. Excel and CSV sample with references to original rows.
  2. Prepared journal, checks and sampling choices for reproducing the selection.

Check that the sample covers the requested period and accounts and has the expected row count. Preparation checks do not certify postings or sample sufficiency. Continue with Vouching to check supporting documents.

05

Pause and check

  1. Before selection, explain which population you are sampling.
  2. In the result, trace a sampled row to the source file.

These pauses help you learn how to use the function. They are not a technical detail quiz.

06

Try it yourself

Repeat with journal-april.csv, which adds an April payment. Keep the random sample of 5 rows and preserve the first result. Check the new population and identify one row in the new sample.
  • journal-april.csv
  • context-en.md

You can make the request, find the sample and trace a row to the journal without manually replacing selected rows.

Tell Vera the client, journal, period, any filters, and the method and size in your audit plan. Ask for Vouching when you want to compare the sample with supporting documents.
