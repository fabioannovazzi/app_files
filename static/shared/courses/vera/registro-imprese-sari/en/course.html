How to use this function

Prepare a Registro Imprese practice with Vera

Learn to provide the case, follow source checks and use the practice plan and document checklist for review.

The explanation and a short practice take about 5–8 minutes. Processing and your questions can extend the session.

Two chats, one lesson

Speak with the teacher using the standard Codex voice. In the working chat, open in the window beside it, the function runs the case using the prepared files and shows its actual results. The teacher follows those results: interrupt, ask questions and change the pace whenever you need.

01

When to use it

A company asks to update its registered PEC address. Prepare the professional’s work from the request and available facts through to the plan for review.

The complete preparation process in a simple case: facts, sources, proposal, checks and review. SARI helps locate guidance; Vera produces a professional-review package without filing.

02

Files and request

Open company-en.md for the request, company, chamber, addresses and stated date. sources-en.md lists public pages to verify. No credentials or technical instructions are needed.

Vera, prepare the Registro Imprese practice described in this file. Check relevant sources and show me the plan, documents to request and proposals to review. Do not access portals or submit the filing.
03

Run the workflow

  1. In the working chat, Vera opens the case and reads the documents. In the voice chat, it explains the practice being prepared and missing facts. Review the chamber, operation and proposed data.
  2. Vera checks current official sources and links proposals to case facts. If a SARI card must be selected, it shows relevant choices and waits for yours. Voice explains the current step.
  3. Open studio_checklist.md and the generated plan. Follow one fact from the request to a proposed field and its source. Review lets you accept, request documents or ask for a change; a requested change still needs to be carried out.
During the lesson, the working chat runs the function and produces the result. If a step is unavailable, explain what is missing and keep the lesson incomplete.
04

Use the result

  1. Practice plan with fields, documents, checks and sources.
  2. Studio checklist, any question drafted for SARI and review handoff with open points.

Check that the plan matches the request. Find a fact requiring confirmation and the evidence to obtain. This is a professional draft: accepted review is neither filing nor portal access.

05

Pause and check

  1. Explain what you give Vera and which result you expect.
  2. Find a proposed field, its supporting document and the professional’s next check.

These pauses help you learn how to use the function. They are not a technical detail quiz.

06

Try it yourself

Read update-en.md and request the new version. Check that address and date match the updated request, missing evidence remains visible and the first version is preserved.
