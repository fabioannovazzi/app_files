# Riscontri del corso — consultare dopo l’esecuzione

Soluzione didattica indipendente. NON è una fonte economica, un caso approvato
o un risultato prodotto da Vera: non importarla tra gli input di valutazione.
Sono assunti FCFF di 100.000 euro a fine 2027, flusso terminale annuo 2028 di
100.000 euro, crescita zero e stessa convenzione annuale per i due tassi.

## Calcolo manuale iniziale (10%)
PV primo flusso = 100.000 / 1,10 = 90.909,09 euro.
Terminale a fine 2027 = 100.000 / (0,10 - 0) = 1.000.000 euro.
PV terminale = 1.000.000 / 1,10 = 909.090,91 euro.
Valore operativo = 90.909,09 + 909.090,91 = 1.000.000 euro.
Capitale proprio = 1.000.000 - 300.000 + 50.000 = 750.000 euro.
Peso del terminale = 909.090,91 / 1.000.000 = 90,91%.

## Calcolo manuale alternativo (12%)
PV primo flusso = 100.000 / 1,12 = 89.285,71 euro.
Terminale = 100.000 / 0,12 = 833.333,33 euro.
PV terminale = (100.000 / 0,12) / 1,12 = 744.047,62 euro.
Valore operativo = 833.333,33 euro.
Capitale proprio = 833.333,33 - 300.000 + 50.000 = 583.333,33 euro.
Differenza rispetto al caso iniziale = -166.666,67 euro (-22,22%).
Arrotonda solo per esposizione; tolleranza un centesimo.

## Evidenza mancante e recupero
Senza terminale: nessun valore DCF completo né capitale proprio del metodo.
Il DCF deve restare bloccato; la bozza conserva motivo e fonti disponibili.
Il risultato complessivo può essere partial: significa che ci sono carte di
lavoro incomplete, non che il DCF sia utilizzabile.
Il professionista deve fornire flusso, anno, unità, base e conferma.
Dopo integrazione-it.md, al 10%, i numeri devono tornare quelli iniziali,
con nuova ricevuta e nuovo run. Non riutilizzare l’approvazione di altri run.

## Lista dei controlli
1. Client_id e engagement_id corretti; ogni run usa gli input_id esatti.
2. Debito e terminale rintracciabili alla nota e alle ricevute SHA-256.
3. Excel: formule ricalcolabili e valori di controllo; report coerente.
4. Incarico incompleto, metodo da rivedere, nessuna conclusione accettata.
5. Quattro run separati; iniziale invariato dopo tasso alternativo e recupero.
6. In nuova chat: riaprire esatto run e artefatti, hash identici, senza ricalcolo.
7. Leggere il report dei dati al modello e le decisioni ancora richieste.

La beta non certifica conformità PIV, sostenibilità del terminale, finalità
legale o identità del professionista. Questi riscontri verificano l’aritmetica,
non la bontà economica delle ipotesi.
