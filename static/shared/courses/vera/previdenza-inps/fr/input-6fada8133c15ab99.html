# Relevé contributif fictif

contribution-periods-fr.csv est un relevé simplifié inventé pour la leçon, couvrant le 2025-01-01–2025-06-30 et daté du 2026-08-01. Les lignes constituent tout ce relevé pédagogique. Ce n’est pas un téléchargement officiel INPS et il ne faut pas l’enregistrer comme tel. Une période absente ne prouve pas un défaut de paiement. Pour l’exercice, le relevé du 2026-09-01 remplace le précédent sans établir quand ni pourquoi les données ont changé.
