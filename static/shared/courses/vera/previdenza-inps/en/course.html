How to use this function

Review an INPS case with Vera

Learn to provide a social-security question and documents, check evidence and use the resulting file for professional review.

The explanation and a short practice take about 5–8 minutes. Processing and your questions can extend the session.

Two chats, one lesson

Speak with the teacher using the standard Codex voice. In the working chat, open in the window beside it, the function runs the case using the prepared files and shows its actual results. The teacher follows those results: interrupt, ask questions and change the pace whenever you need.

01

When to use it

Marta wants to understand her contribution record for a period of employment. She has an employer statement and a fictional record of periods.

An Italian private-employment document case. Follow question, sources, chronology, relevant research and draft; no pension calculation or portal operation.

02

Files and request

Open case-en.md, employment-en.md, record-context-en.md and contribution-periods-en.csv. Identify the person, period and question. The teaching record is fictional, not an official export.

  • contribution-periods-en.csv
Vera, review this INPS case for January through June 2025. Explain what the documents show, check relevant official sources and prepare a draft with questions and documents to request.
03

Run the workflow

  1. In the working chat Vera reads the files and summarizes question, period and Italian framework for confirmation. Voice explains the process and helps separate available information from open questions.
  2. Vera organizes facts and chronology, links facts to documents, researches the relevant framework and prepares the file through the current workflow. Voice follows actual evidence and results without anticipating a conclusion.
  3. Open the generated memo, chronology and document requests. Start with the answer to the question, trace a fact to its source and check what remains for review.
During the lesson, the working chat runs the function and produces the result. If a step is unavailable, explain what is missing and keep the lesson incomplete.
04

Use the result

  1. A study memo in Word and text, clearly marked as a draft for professional review.
  2. Chronology, evidence matrix and document requests to continue the case.

Check period, person and cited documents. An employment statement and a period appearing in a record are different evidence. Check source scope and missing information before drawing conclusions or making a report.

05

Pause and check

  1. Before analysis, state the question the case file should answer.
  2. In the memo, find a fact, its source and the next useful clarification.

These pauses help you learn how to use the function. They are not a technical detail quiz.

06

Try it yourself

Repeat the request with the practice inputs, including an updated record. Preserve the first file and compare which observations and requests change. Do not infer when or why data changed if the documents do not explain it.

You can start the review, supply documents, read the memo and sources and update the work with new evidence.

Tell Vera the INPS question, period, people and available documents, including any deadlines. Review scope and evidence and use the draft in the normal professional process.
