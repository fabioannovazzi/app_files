How to use this function

Organise a client folder with Vera

Learn to obtain an organisation plan, review destinations and apply approved changes to a folder.

The explanation and a short practice take about 5–8 minutes. Processing and your questions can extend the session.

Two chats, one lesson

Speak with the teacher using the standard Codex voice. In the working chat, open in the window beside it, the function runs the case using the prepared files and shows its actual results. The teacher follows those results: interrupt, ask questions and change the pace whenever you need.

01

When to use it

Ciclo Arco’s folder contains an agreement, an exact copy and an internal meeting note in two intake folders. We will prepare a readable plan and try it on a teaching copy.

One client and fictional local files. Applying changes requires an explicit choice; the lesson does not change the real studio archive.

02

Files and request

Open client and inspect Da archiviare and Download. Read the agreement and meeting note. Vera copies them into a separate teaching client and uses the workflow’s studio folder policy. Default folder labels are Italian.

  • maintenance-en.md
  • maintenance-copy-en.md
  • meeting-en.md
Vera, propose how to organise this Ciclo Arco folder. Show documents, destinations and duplicate copies before moving anything.
03

Run the workflow

  1. The working chat creates the teaching client and captures its file snapshot. Vera reads the necessary evidence and proposes categories and destinations from the contents.
  2. Open the generated review page. Inspect every proposal, keep or edit the destination and decide how to handle the exact copy. The plan remains proposed until reviewed.
  3. After those decisions, Vera summarises planned moves and separately asks whether to apply them. If you approve the teaching-copy changes, it executes the plan and shows the resulting folders and operation journal.
During the lesson, the working chat runs the function and produces the result. If a step is unavailable, explain what is missing and keep the lesson incomplete.
04

Use the result

  1. Review page and plan: starting files, proposed destinations, reasons and saved decisions.
  2. After authorized application: organised folder and journal for checking moves and considering rollback.

Follow a document from its original location to its destination. The exact copy is retained in the duplicate-review area rather than deleted. Reviewing a proposal is separate from authorizing file moves.

05

Pause and check

  1. Before the plan, identify the client and teaching folder.
  2. Before application, explain one chosen destination and check the planned moves.

These pauses help you learn how to use the function. They are not a technical detail quiz.

06

Try it yourself

Use the new client copy in the practice files, which adds update-en.md. Request another plan, review where the update belongs with its agreement and decide whether to apply it. Preserve the demonstration.
