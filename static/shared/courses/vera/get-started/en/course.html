Get started with Vera

Learn to ask for work, provide files, read the result and request a change. We will try one task together using prepared fictional documents.

5–8 minutes of explanation and a short exercise. Processing and questions can take longer.

You can skip, pause or revisit this introduction at any time. Completing it is not required to use Vera.

Start this course

Codex

  1. Open Codex on your computer with Vera installed and select @Vera in a chat.
  2. Copy the request below, paste it into the chat and send it.
  3. Turn on Codex voice in this chat. The assistant will guide you to open the second working chat in another window: listen and ask questions here, and watch the work and results there.

The fictional lesson files are already included in the plugin. You can also take the lesson in writing. This button copies the request; the lesson starts when you send it in Codex.

Start in Claude Cowork

Open Cowork with Vera installed and a connected folder for the lesson. Copy and send this request: the lesson takes place in writing in one conversation.

Your first task, step by step

01

What do you work on?

Briefly describe your work and what you would like to try. Vera suggests 3–4 relevant functions and the result each produces. Choose just one to start. If you have no preference, we can compare a fictional bank statement and bank ledger.

02

Ask for the work and look at the files

Open the documents prepared for the chosen case. You do not need commands: describe the result you want, which files to use and the period or question. For example: “Compare this bank statement with the ledger and show me the transactions to review.”

03

Follow the work and open the result

Vera runs the current function, explains any questions and opens the actual result. See where it is saved, how to reopen it, which figure to check against its source and what still needs your review.

04

Request a small change

Use the prepared practice variation: an updated period or an additional document. Ask Vera to run the work again. Compare the new result with the first, which remains available.

05

Choose what to learn next

Try describing how you would request similar work and which files you would provide. Finish with links to the results and choose your next course from the suggestions. The other courses are optional and do not start automatically.

What data reaches the model

The Codex or Claude model reads what you share about your work, the fictional files and the results we open in the conversation. Progress is saved on your computer in Codex or in the connected folder in Cowork; it is not sent to Mparanza. This does not mean offline model processing. You do not need real client documents for this introduction.
