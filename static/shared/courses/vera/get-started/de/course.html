Erste Schritte mit Vera

Lernen Sie, eine Aufgabe zu beschreiben, Dateien bereitzustellen, das Ergebnis zu lesen und eine Änderung anzufordern. Gemeinsam bearbeiten wir einen Fall mit vorbereiteten fiktiven Dokumenten.

5–8 Minuten Erklärung und eine kurze Übung. Verarbeitung und Fragen können länger dauern.

Sie können diese Einführung jederzeit überspringen, unterbrechen oder wiederholen. Sie ist keine Voraussetzung für die Nutzung von Vera.

Diese Lektion starten

Codex

  1. Öffnen Sie Codex auf Ihrem Computer mit installiertem Vera und wählen Sie @Vera in einem Chat aus.
  2. Kopieren Sie die folgende Anfrage, fügen Sie sie in den Chat ein und senden Sie sie ab.
  3. Aktivieren Sie die Sprachfunktion von Codex in diesem Chat. Der Assistent hilft Ihnen, den zweiten Arbeitschat in einem weiteren Fenster zu öffnen: Hier hören Sie zu und stellen Fragen, dort verfolgen Sie die Arbeit und die Ergebnisse.

Die fiktiven Übungsdateien sind bereits im Plugin enthalten. Sie können die Lektion auch schriftlich durchgehen. Diese Schaltfläche kopiert die Anfrage; die Lektion beginnt, wenn Sie sie in Codex absenden.

In Claude Cowork starten

Öffnen Sie Cowork mit installiertem Vera und einem verbundenen Ordner für die Lektion. Kopieren und senden Sie diese Anfrage: Die Lektion findet schriftlich in einem einzigen Chat statt.

Eine erste Aufgabe, Schritt für Schritt

01

Woran arbeiten Sie?

Beschreiben Sie kurz Ihre Arbeit und was Sie ausprobieren möchten. Vera schlägt 3–4 passende Funktionen mit ihren Ergebnissen vor. Wählen Sie zunächst nur eine. Ohne besondere Präferenz können wir einen fiktiven Kontoauszug mit dem Bankkonto im Hauptbuch vergleichen.

02

Beschreiben Sie die Aufgabe und sehen Sie die Dateien an

Wir öffnen die vorbereiteten Dokumente des gewählten Falls. Sie brauchen keine Befehle: Beschreiben Sie das gewünschte Ergebnis, die Dateien und den Zeitraum oder die Frage. Zum Beispiel: „Vergleiche diesen Kontoauszug mit dem Bankkonto im Hauptbuch und zeige mir die zu prüfenden Buchungen.“

03

Verfolgen Sie die Arbeit und öffnen Sie das Ergebnis

Vera führt die aktuelle Funktion aus, erklärt Rückfragen und öffnet das tatsächliche Ergebnis. Sie sehen, wo es gespeichert ist, wie Sie es wieder öffnen, welche Zahl Sie an der Quelle prüfen und was noch Ihre fachliche Prüfung erfordert.

04

Fordern Sie eine kleine Änderung an

Verwenden Sie die vorbereitete Übungsvariante: einen aktualisierten Zeitraum oder ein zusätzliches Dokument. Bitten Sie Vera, die Aufgabe erneut auszuführen. Wir vergleichen das neue Ergebnis mit dem ersten, das erhalten bleibt.

05

Wählen Sie den nächsten Kurs

Beschreiben Sie, wie Sie eine ähnliche Aufgabe anfordern würden und welche Dateien Sie bereitstellen würden. Zum Abschluss erhalten Sie Links zu den Ergebnissen und wählen einen nächsten Kurs. Die weiteren Kurse sind freiwillig und starten nicht automatisch.

Welche Daten das Modell erhält

Das Modell von Codex oder Claude liest Ihre Angaben zur Arbeit, die fiktiven Dateien und die in der Unterhaltung geöffneten Ergebnisse. Der Fortschritt wird in Codex auf Ihrem Computer oder in Cowork im verbundenen Ordner gespeichert und nicht an Mparanza gesendet. Das bedeutet keine Offline-Verarbeitung durch das Modell. Für diese Einführung brauchen Sie keine echten Mandantendokumente.
