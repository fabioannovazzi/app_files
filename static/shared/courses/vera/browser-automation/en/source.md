# Teach a repeatable browser step

Entirely fictional teaching case.

A fictional local portal lists one document with a download button. The task is to repeat that single download. There are no credentials, payments or client records in the teaching site.

| Fictional website element | Observable evidence | Limit |
| --- | --- | --- |
| Document list | One document named DEMO-01 | Synthetic content |
| Download button | synthetic-download.txt | One intended operation |
| Expected file | Identifying text for the case | Must be opened and checked |

The procedure rests on the observed page and actual downloaded content. A button's presence does not prove a successful download.

Local fictional website and read/download operation only. No access to a real accounting system is simulated.
