## 1. When to use it · 45 s

Connect the function to a concrete professional task.

Learn to start from a client request and documents, obtain a reviewable matter file and identify what is needed before opening.

Beta Laboratorio requests help with an incomplete delivery. We have its request, a supply summary and a small fictional firm register. We prepare the matter for the lawyer’s review.

This function organizes matter opening. Conflict, engagement, deadline and opening decisions follow the normal review process.

## 2. Files and request · 60 s

Open the files in the working window and show how to request the result.

Open request-en.md, supply-en.md and register.csv. The request identifies client, counterparty, objective and reported urgency; the supply record documents the case; the register shows the fictional matters available for checking.

Lucia, prepare a new matter for Beta Laboratorio concerning Gamma Forniture’s delivery. Use these documents and show the matter file, missing information and decisions to review before opening.

## 3. Run the workflow · 105 s

Explain the step happening now and wait for its actual result.

Lucia creates the teaching case, imports documents and reconstructs the client, parties, request and timeline. The voice chat follows which information comes from each source.

The working chat prepares the matter summary, conflict-check candidates, engagement scope and any deadline points. Missing information stays visible.

Lucia generates the package and opens review. Inspect the conflict, engagement, deadline and opening decisions and how a real decision is saved and applied to the file.

During the lesson, the working chat runs the function and produces the result. If a step is unavailable, explain what is missing and keep the lesson incomplete.

## 4. Use the result · 75 s

Open the document just produced and show where to start reading.

Opening memo and information request: start with objective, parties and available documents; identify what to ask the client.

Folder plan and review page: show how to organize the file and which decisions are needed. Status distinguishes a prepared dossier from a matter ready to open.

Compare client and counterparty with the request and check the scope of the register examined. Read the engagement proposal and deadline points before deciding. A memo’s existence does not mean the engagement was accepted.

## 5. Pause and check · 45 s

Make these checks at the indicated points during the work.

Before preparation: identify the client, counterparty and requested outcome.

In the dossier: show where to find missing documents and decisions still awaiting review.

These pauses help you learn how to use the function. They are not a technical detail quiz.

## 6. Try it yourself · 60 s

Let the user formulate the request and guide their attempt.

Add update-en.md: Gamma proposes a delivery date for the remaining components. Ask Lucia to update the dossier with this correspondence while preserving the preceding version.

The new version includes the proposal and its source without assuming delivery or acceptance. You can identify which matter points need further review.

To repeat, supply the request, documents and actually available register; state whether the client is new or existing, then review the package before opening the matter.
