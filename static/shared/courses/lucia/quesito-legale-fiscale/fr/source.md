# D'une question générale à une réponse vérifiable

Cas pédagogique entièrement fictif.

Un client fictif demande si une dépense est déductible. La facture décrit un service, mais sujet, période, régime et utilisation réelle sont inconnus. La leçon précise la question sans donner d'avis fiscal sur le cas.

| Élément fictif | Disponible | À clarifier |
| --- | --- | --- |
| Facture Q1 | Description et montant du service | Utilisation réelle |
| Question client | Intérêt pour la déduction | Sujet, régime et période |
| Sources juridiques | Non sélectionnées dans le microcas | Cadre applicable après clarification |

Q1 soutient une description documentaire, pas les conditions fiscales. Les faits manquants peuvent changer recherche et conclusion.

Leçon de méthode, sans règle fiscale substantielle à appliquer. Le cas réel nécessite des sources primaires actuelles et pertinentes.
