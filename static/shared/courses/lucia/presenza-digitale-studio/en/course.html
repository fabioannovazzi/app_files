How to use this function

Prepare the firm’s website with Lucia

Learn to start from firm information, obtain a working website and review it before choosing publication.

The explanation and a short practice take about 5–8 minutes. Processing and your questions can extend the session.

Start this course

Codex

  1. Open Codex on your computer with Lucia installed and select @Lucia in a chat.
  2. Copy the request below, paste it into the chat and send it.
  3. Turn on Codex voice in this chat. The assistant will guide you to open the second working chat in another window: listen and ask questions here, and watch the work and results there.

The fictional lesson files are already included in the plugin. You can also take the lesson in writing. This button copies the request; the lesson starts when you send it in Codex.

Start in Claude Cowork

Open Cowork with Lucia installed and a connected folder for the lesson. Copy and send this request: the lesson takes place in writing in one conversation.

Two chats, one lesson

Speak with the teacher using the standard Codex voice. In the working chat, open in the window beside it, the function runs the case using the prepared files and shows its actual results. The teacher follows those results: interrupt, ask questions and change the pace whenever you need.

01

When to use it

Studio Arco has no website. We build a page introducing the firm, its supplied activities and contact path, using only the fictional profile.

First informational website for an Italian practice. The demonstration produces a local version for review; later publication needs a destination and approvals for the exact site.

02

Files and request

Open lucia-studio-en.md with the audience, activities, contact and hours. Select it for the lesson and choose a teaching folder. A logo or photographs are not required; missing facts stay missing.

  • lucia-studio-en.md
Lucia, prepare Studio Arco’s first website from this information: introduction, activities and contact on one page readable on desktop and phone. Show a local version for review.
03

Run the workflow

  1. The working chat records the selected material and prepares the project. Lucia summarises the facts to use and proposes content order, typography and colours; the voice chat links these choices to the visitor’s questions.
  2. The workflow implements HTML and styles and checks files and links. Open the working site and move through introduction, activities and contact, checking how the source information became copy.
  3. Review the page at desktop and phone widths with its captured images. Check identity and claims, readability and links. Lucia shows validation status and what remains before real publication.
During the lesson, the working chat runs the function and produces the result. If a step is unavailable, explain what is missing and keep the lesson incomplete.
04

Use the result

  1. Working local website and editable files: the result to open and review.
  2. Source and design summary, technical checks, desktop and phone captures and review status.

Compare activities, contact and hours with the profile. There should be no invented qualifications, results or contact details. The firm owns professional review; a checked local site is not an already published site.

05

Pause and check

  1. Before building, name the visitor and where they should find the contact.
  2. At review, open the contact section on the phone layout and check hours and readability.

These pauses help you learn how to use the function. They are not a technical detail quiz.

06

Try it yourself

Use lucia-update-en.md to add Friday hours in a new version while retaining the earlier information. Reopen both layouts and verify that the addition does not replace the other hours.
  • lucia-studio-en.md
  • lucia-update-en.md

You can supply material, request the site, find the working version and check a change. You know that external preview and final publication are later choices bound to approved files.

For your practice, identify an existing or first website, public-use materials and objective. After review choose the destination; the workflow packages and publishes only the exact authorized version.

The kit contains fictional files and a prepared outline. Demonstration and practice results come from fresh runs of the current function.

The lesson library, profile and progress stay on your computer. They are not sent to Mparanza. Voice and content read in chat are processed by your OpenAI account: local storage does not mean offline inference.
