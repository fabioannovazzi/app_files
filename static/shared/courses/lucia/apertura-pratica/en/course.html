How to use this function

Prepare a new matter with Lucia

Learn to start from a client request and documents, obtain a reviewable matter file and identify what is needed before opening.

The explanation and a short practice take about 5–8 minutes. Processing and your questions can extend the session.

Start this course

  1. Open Codex on your computer with Lucia installed and select @Lucia in a chat.
  2. Copy the request below, paste it into the chat and send it.
  3. Turn on Codex voice in this chat. The assistant will guide you to open the second working chat in another window: listen and ask questions here, and watch the work and results there.

The fictional lesson files are already included in the plugin. You can also take the lesson in writing. This button copies the request; the lesson starts when you send it in Codex.

Two chats, one lesson

Speak with the teacher using the standard Codex voice. In the working chat, open in the window beside it, the function runs the case using the prepared files and shows its actual results. The teacher follows those results: interrupt, ask questions and change the pace whenever you need.

01

When to use it

Beta Laboratorio requests help with an incomplete delivery. We have its request, a supply summary and a small fictional firm register. We prepare the matter for the lawyer’s review.

This function organizes matter opening. Conflict, engagement, deadline and opening decisions follow the normal review process.

02

Files and request

Open request-en.md, supply-en.md and register.csv. The request identifies client, counterparty, objective and reported urgency; the supply record documents the case; the register shows the fictional matters available for checking.

  • request-en.md
  • supply-en.md
  • register.csv
Lucia, prepare a new matter for Beta Laboratorio concerning Gamma Forniture’s delivery. Use these documents and show the matter file, missing information and decisions to review before opening.
03

Run the workflow

  1. Lucia creates the teaching case, imports documents and reconstructs the client, parties, request and timeline. The voice chat follows which information comes from each source.
  2. The working chat prepares the matter summary, conflict-check candidates, engagement scope and any deadline points. Missing information stays visible.
  3. Lucia generates the package and opens review. Inspect the conflict, engagement, deadline and opening decisions and how a real decision is saved and applied to the file.
During the lesson, the working chat runs the function and produces the result. If a step is unavailable, explain what is missing and keep the lesson incomplete.
04

Use the result

  1. Opening memo and information request: start with objective, parties and available documents; identify what to ask the client.
  2. Folder plan and review page: show how to organize the file and which decisions are needed. Status distinguishes a prepared dossier from a matter ready to open.

Compare client and counterparty with the request and check the scope of the register examined. Read the engagement proposal and deadline points before deciding. A memo’s existence does not mean the engagement was accepted.

05

Pause and check

  1. Before preparation: identify the client, counterparty and requested outcome.
  2. In the dossier: show where to find missing documents and decisions still awaiting review.

These pauses help you learn how to use the function. They are not a technical detail quiz.

06

Try it yourself

Add update-en.md: Gamma proposes a delivery date for the remaining components. Ask Lucia to update the dossier with this correspondence while preserving the preceding version.
  • request-en.md
  • supply-en.md
  • update-en.md

The new version includes the proposal and its source without assuming delivery or acceptance. You can identify which matter points need further review.

To repeat, supply the request, documents and actually available register; state whether the client is new or existing, then review the package before opening the matter.
