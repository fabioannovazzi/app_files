How to use this function

Create an HTML presentation with Clara

Learn to turn documents and a clear request into usable slides, check their message and present them in a browser.

The explanation and a short practice take about 5–8 minutes. Processing and your questions can extend the session.

01

When to use it

Officina Arco needs to explain a proposed intake process to staff. Start with the meeting notes.

An internal presentation based on the notes, with slides and speaker notes. The procedure remains a proposal; no undocumented results or charts are added.

02

Files and request

Open brief-en.md. State audience, purpose and meeting message: discuss the proposal, rather than announce an adopted procedure.

  • brief-en.md
Clara, make a short HTML presentation from these notes for the staff meeting. Explain the problem, proposal, roles and decision. Keep its proposed status visible and add speaker notes.
03

Run the workflow

  1. In the working chat Clara reads the notes and proposes the presentation sequence. Voice explains how to specify audience and purpose and helps you check the order of the messages.
  2. Clara composes slides through the current workflow and checks readability, content and navigation. Voice follows actual results and answers questions while the presentation is prepared.
  3. Open the generated presentation. Use the arrow keys, open speaker notes and compare a slide with the original document. Identify the proposal and requested decision.
During the lesson, the working chat runs the function and produces the result. If a step is unavailable, explain what is missing and keep the lesson incomplete.
04

Use the result

  1. A standalone HTML presentation with notes and navigation, ready to open in a browser.
  2. The presentation package, editable materials and checks for the version produced.

Check that slides reflect the notes, distinguish proposal from current practice and remain readable. Attractive layout does not justify invented results. Check the final slide and speaker notes too.

05

Pause and check

  1. Before creating slides, identify your audience and the decision they should make.
  2. In the presentation, find a message and the note that supports it.

These pauses help you learn how to use the function. They are not a technical detail quiz.

06

Try it yourself

Add new-audience-en.md and request a new version for new colleagues with the incomplete-request example. Preserve the first and explain how audience and purpose changed the presentation.
  • brief-en.md
  • new-audience-en.md

You can supply sources and an objective, read and present the result and request a version for another audience.

Ask Clara for an HTML presentation, attach your materials and state audience, purpose, language and messages to preserve. You can also invoke deck correction for an existing presentation.

The kit contains fictional files and a prepared outline. Demonstration and practice results come from fresh runs of the current function.

The lesson library, profile and progress stay on your computer. They are not sent to Mparanza. Voice and content read in chat are processed by your OpenAI account: local storage does not mean offline inference.
