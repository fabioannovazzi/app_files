How to use this function

Correct a presentation with Clara

Learn to turn feedback into a verifiable slide change while retaining control of what changes.

The explanation and a short practice take about 5–8 minutes. Processing and your questions can extend the session.

Two chats, one lesson

Speak with the teacher using the standard Codex voice. In the working chat, open in the window beside it, the function runs the case using the prepared files and shows its actual results. The teacher follows those results: interrupt, ask questions and change the pace whenever you need.

01

When to use it

The Officina Arco proposal presentation already exists. Feedback updates the person proposed to gather requests.

A targeted correction to an existing HTML presentation: understand feedback, edit a copy and compare. The workflow does not recreate the whole presentation for every change.

02

Files and request

Open original-deck-en.html and feedback-en.md. The original-work-en.zip package contains editable materials for Clara. You identify the presentation and the change.

  • original-deck-en.html
  • original-work-en.zip
  • feedback-en.md
Clara, correct this presentation using the attached feedback: Elena will gather and clarify requests instead of Sara. Paolo keeps his role. Preserve the original and show me the change.
03

Run the workflow

  1. In the working chat Clara reads the presentation and feedback and summarizes the intended change. Voice helps you check which slide and meaning will change.
  2. Clara applies the request to a copy through the current workflow, preserves other slides and checks the revision. Voice follows actual progress and explains when ambiguous feedback needs clarification.
  3. Open the original and corrected copy. Compare the responsibilities slide and then an unchanged slide. Check the visible result, notes and change summary.
During the lesson, the working chat runs the function and produces the result. If a step is unavailable, explain what is missing and keep the lesson incomplete.
04

Use the result

  1. A corrected presentation copy, with the original preserved.
  2. The interpreted request, before/after comparison and checks of the corrected version.

Check that the proposed person changes without changing Paolo’s role or declaring the procedure approved. Other slides should retain meaning, order and style. The result must reflect the feedback, beyond passing a technical check.

05

Pause and check

  1. Before the edit, explain what should change and what should stay the same.
  2. Afterwards, find the requested change and something preserved.

These pauses help you learn how to use the function. They are not a technical detail quiz.

06

Try it yourself

Start again from the original with practice-feedback-en.md. Ask to collect staff questions first, replacing only the closing trial step. Preserve the copies and check that the conclusion matches the request.

You can identify a presentation, give precise feedback and verify a revision without losing the original.

Show Clara the presentation and describe the change, including by native voice conversation. Supply any new figures or wording. Clara resolves ambiguity and edits a copy; PPTX work also includes reviewing the change plan before application.
