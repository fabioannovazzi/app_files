I vantaggi
di un plugin.

Più intelligenza per lo stesso budget

Usi i token del tuo abbonamento. La capacità inclusa nel piano costa meno dell’equivalente uso via API: puoi dedicare più intelligenza al problema, anche quando il lavoro richiede un’elaborazione agentica intensa.

Un ambiente già capace di eseguire il lavoro

Il plugin può usare un agente che pianifica, lavora sui file e richiama strumenti. Costruire una funzione significa poter contare su queste capacità fin dall’inizio.

Migliora insieme alla piattaforma

Modelli più capaci, una migliore gestione del contesto e nuovi strumenti possono far progredire anche i plugin. Ogni sviluppatore può beneficiare di un investimento molto più grande del proprio.

Si distribuisce nell’app che usi già

Installazione e aggiornamenti passano dalla piattaforma. Il plugin può arrivare agli utenti attraverso directory e raccomandazioni, e può essere condiviso con un gruppo di lavoro. Lo studio adotta nuove funzioni nello stesso ambiente.

Può diventare un’applicazione completa

I plugin possono avere pannelli interattivi, editor di file e collegamenti ad altri servizi. Possono anche avviare attività quando arriva un evento, come un nuovo documento. OpenAI sta aprendo ai plugin le stesse superfici con cui costruisce ChatGPT.
