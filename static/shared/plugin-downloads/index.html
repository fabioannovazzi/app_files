Come installare

Usa Codex nell’app desktop. Questi ZIP sono per Codex: non caricarli come allegati in ChatGPT web o nei plugin di Claude Cowork.

  1. Estrai tutto lo ZIP.

    Su Mac, fai doppio clic; su Windows, scegli “Estrai tutto”. Sposta la cartella estratta in una posizione stabile, per esempio Documenti/Mparanza. Conserva l’intera cartella, comprese le cartelle nascoste.

  2. Apri la cartella in Codex.

    Avvia una chat locale nella cartella vera-codex-plugin, clara-codex-plugin o lucia-codex-plugin appena estratta. È la cartella che contiene “plugins” e il file LEGGIMI_INSTALLAZIONE.txt.

  3. Chiedi a Codex di installare il plugin.

    Scegli il prodotto, copia la richiesta e incollala nella chat. Codex può chiederti il permesso di registrare e installare il plugin locale.

  4. Riavvia e verifica in una nuova chat.

    Dopo l’installazione, chiudi e riapri l’app. Apri una nuova chat nella tua cartella di lavoro e chiedi a Codex di controllare che il plugin sia attivo nella versione indicata sopra e disponibile nella nuova chat. Poi descrivi il lavoro da svolgere. Una chat già aperta può conservare le vecchie istruzioni.

Se hai già installato il plugin

La copia locale e quella del Marketplace sono installazioni distinte. La richiesta qui sopra serve anche per passare da una versione precedente: fai verificare la nuova installazione e lascia attiva una sola copia dello stesso prodotto. Il download da solo non aggiorna il plugin.

Per un prossimo aggiornamento, scarica il nuovo ZIP in una cartella separata e ripeti la procedura indicando quella cartella. Conserva le cartelle dei plugin e tieni i documenti dei clienti nella tua normale cartella di lavoro.

Se l’installazione si ferma

Invia nel gruppo il nome del plugin, la versione, il sistema operativo e il testo completo dell’errore, senza allegare documenti dei clienti. In un account gestito dallo studio, l’installazione di plugin locali può richiedere l’intervento dell’amministratore.

Comandi per l’installazione manuale

Se usi il terminale e il comando codex è disponibile, sostituisci il percorso di esempio con il percorso assoluto della cartella estratta. Esegui i comandi del prodotto selezionato sopra, poi riavvia l’app. Se il catalogo è già registrato, fai controllare a Codex a quale cartella punta prima di aggiornarlo.

codex plugin marketplace add "/percorso/vera-codex-plugin"
codex plugin add vera@mp-vera
codex plugin list --json
