# Parere contrapposto

Resolve `../../modules/deep-research-validator` from this skill directory when
it exists; otherwise resolve `../../../deep-research-validator` in repository
source. Read its `skills/mparanza-adversarial-opinion/SKILL.md` completely and follow it.
Treat the Lucia root as the invoking product root. The method, scope rule,
durable helper and comparison checks are shared with the other product.
Do not fork the method or add an opposing examination to informational research.

For a supplied position without a reviewed original and answer contract, first
follow `../mparanza-quesito-legale-fiscale/SKILL.md`. Review the opposing result with
`../mparanza-legal-tax-answer-review/SKILL.md`; do not recursively request an opposing
opinion about the opposing opinion. Final choices remain with the professional.
