# Geneva adaptation of the existing function

Use the common planning workflow with explicit reporting_currency CHF and presentation.language fr. French fixed report labels and number presentation are supported; write case-authored narratives, tables, actions and financing assessments in the selected language as well. Currency and language do not choose the entity's jurisdiction. Review actual financing, payroll, social costs and tax assumptions from case evidence; do not import Italian defaults or invent Swiss rates. HTML and PDF use the same source-bound plan and arithmetic. No new Swiss-specific planning function is introduced.

Official starting sources and the complete catalogue assessment are in Vera’s `references/localization/geneva/`. Verify current applicability for each actual case.
