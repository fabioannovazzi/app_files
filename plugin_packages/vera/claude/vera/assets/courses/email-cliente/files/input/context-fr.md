# CLIENT-001

Dossier fictif, campagne Italie 2026. Le client a fourni une CU et un F24 lisibles. Le cabinet souhaite demander s’il existe d’autres CU et si tous les F24 de la campagne ont été transmis. Le courriel se limite à ces deux confirmations documentaires. Les fichiers conservent les noms et champs des formulaires italiens. Sélection des demandes et approbation du brouillon restent à effectuer pendant la leçon.
