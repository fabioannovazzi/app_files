# Geneva adaptation of the existing function

Initialize with `--jurisdiction CH-GE --language fr` (or the chosen language). This keeps one registry-practice workflow and its existing exact-source and review gates. Read the current Geneva Registre du commerce documentation/forms and the applicable federal provisions. Establish the legal form, competent authority, operation and required evidence before proposing steps.

The existing internal `competent_chamber` container identifies the competent authority; for Geneva enter the actual Registre du commerce and territorial basis, not an invented Italian chamber. Use position_types `registre_du_commerce` and, when justified, `other`. `dire_steps` is the existing step container: populate it with the evidenced local procedure, never pretend DIRE is used in Geneva. `sari_question_draft` contains an optional question to the actual authority; it is not sent. Use client_identity.enterprise_id for an IDE, preserving its source. Italian identifiers are optional cross-border facts only.

Carry CH-GE on both intake and plan. A mismatch or Italian position code blocks validation. The official-source allowlist includes ge.ch, www.ge.ch, www.fedlex.admin.ch and www.zefix.admin.ch. It is a network boundary, not a semantic source selector: inspect the actual current form, article and operation. No portal access, signing, notarial act or filing is added. Output remains a source-backed professional draft with ready_to_file false.

Official starting sources and the complete catalogue assessment are in Vera’s `references/localization/geneva/`. Verify current applicability for each actual case.
