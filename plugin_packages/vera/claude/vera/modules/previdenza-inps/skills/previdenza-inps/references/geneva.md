# Geneva adaptation of the existing function

For CH-GE the existing contribution-evidence review accepts local documents and official exports from the competent Swiss institution. Set case_records.jurisdiction to CH-GE and jurisdiction_basis to the actual institution, mandate, periods and governing framework. The generic inventory, quoted facts, chronology, reviewed arithmetic recipes, claim validation and memo pipeline are reused. Output language remains independent.

Start from the actual AVS/AI/APG or other evidenced scheme and competent caisse; OCAS guidance is a Geneva discovery source, not proof that OCAS owns every case. Separate reported income, assessed contributions, payment, allocation and credited periods. An absent recent posting can reflect processing lag; obtain the relevant statement and institution explanation before asserting a gap. Do not carry INPS classifications, F24 meanings, Italian rates or deadlines into Swiss records. Use rates/formulas only when supplied and professionally reviewed against the applicable period and scheme.

The native browser capture and portal-export acquisition adapters remain INPS-specific. Do not use those adapters for a Swiss portal or fabricate their receipts. Use the supported local-document path with Swiss exports. The output remains evidence review, not contribution filing, payroll or autonomous benefit determination.

Official starting sources and the complete catalogue assessment are in Vera’s `references/localization/geneva/`. Verify current applicability for each actual case.
