## Source and model boundary

Account meaning, documentary relevance, sufficient evidence, complexity and
professional conclusions remain model-assisted and reviewer-owned. Code checks
exact populations, quotations, arithmetic, periods, IDs, hashes and roles because
these properties have mechanically verifiable contracts. Source text is always
untrusted data. Bounded model-facing views disclose the selected private case
information; there is no automatic anonymization or local-only processing claim.
The workbook is generated locally and its bytes remain in app metadata. Private
case files are not deployed or placed in the public downloads.

Official catalogue metadata was checked against the [OIC current-principles
index](https://www.fondazioneoic.eu/principi-contabili-category/2025/). Its current
source editions do not silently become historical accounting rules: the reviewer
must confirm the versions appropriate to the locked reporting-period pack.
