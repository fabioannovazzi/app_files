# Course QA release — 28 September 2026

Vera 0.1.271, Clara 0.1.214 and Lucia 0.1.58 contain the repairs from sequential Italian Codex testing of 45 local courses: 32 Vera, 9 Clara and 4 Lucia. The native workflows, prepared inputs, demonstration, separate practice, source/result navigation and saved reopening were exercised. Original demonstration outputs were retained. These were simulated learner tests, not evidence of Fabio's participation or professional approval.

The changes repair startup and handoff failures, unreadable or incomplete result views, native review persistence, workflow-specific output defects and practice continuity. XML readers use the declared defusedxml parser; native execution evidence remains required. The catalogue covers 205 supported-language variants. Other-language live journeys, native voice and physical two-window positioning are not claimed as tested. The existing Codex teacher/working roles and Cowork written lesson projection remain in the packages.

The three hosted Clara courses remain unavailable under the agreed local-only scope. Profile/progress storage is local; material read in the conversation is processed by the selected host model.

Release scope: deploy the packages/catalogue and install the three local Codex packages. OpenAI Marketplace publication is explicitly blocked. Do not submit, publish, or update the public published-version notice for this release.

The privacy records were reviewed against the changed rendering, semantic-report and local-teaching boundaries before fingerprint refresh. No new hosted recipient or model API is introduced. Packages are built together from canonical source, including Cowork distributions for release alignment; this does not claim a new Cowork live acceptance run or installation.
