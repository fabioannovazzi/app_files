# Get started with Vera

The course catalogue now offers **Inizia a usare Vera / Get started with Vera**
before the workflow list, in Italian, English, French, German and Spanish.
The introduction asks about the user's work, suggests three or four relevant
courses, and teaches the general interaction through one existing prepared case:
request the work, inspect its files, run the real function, open and check the
actual result, then request the prepared practice variation and compare results.
It ends with saved result links and a chosen next course; it does not start that
course automatically or require the longer onboarding programme.

Codex retains the teacher/working chats and native voice guidance. Cowork uses
one written conversation and its connected lesson folder. Both use the current
installed specialist and prepared course. The introduction is not a fabricated
professional workflow, does not add to the 45 workflow-kit count, and never
manufactures user answers, professional approval or completed practice.

Vera advances to 0.1.275. Clara advances to 0.1.218 solely for the reviewed shared
catalogue/projection source fingerprint; no Clara introduction is added. Lucia's
package remains unchanged. No new hosted recipient, model API or feedback
transport is introduced. Marketplace publication and the published-version
notice are excluded.
