# Clara 0.1.194 and Lucia 0.1.42 — reusable desktop teaching

The release adds Impara con Clara and Impara con Lucia, using one shared local
stdlib lifecycle derived from Vera. First use includes an interview and 3–4
current specialist workflows; later sessions can teach a workflow again without
resetting the profile. Native OpenAI voice belongs to the teaching chat, while a
second visible native chat runs bounded steps and returns actual artifacts.
Clara and Lucia retain separate OS-user profiles and reject cross-product state.
No custom voice/model API or Mparanza tutorial transport is introduced.

Clara's OpenAI projection now preserves complete specialist instructions and
references so teaching can follow the current workflow rather than a short
marketplace card. Cowork omits both learning skills, helpers, fixtures and gates.
Vera's runtime and Cowork bytes are unchanged; its shared-page privacy review
was refreshed and the repository archive hash recorded separately from its
already published archive.
