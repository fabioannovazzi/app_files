This release selects 44 reviewed prepared kits (200 language versions) and
retains the existing purchase-invoice lesson (five language versions). Ten of
the eleven replacement kits were completed. The replacement purchase-invoice
kit remains authored but unaccepted: the current Mac cannot yet satisfy the
native isolated-worker qualification. No new invoice-audit output is claimed.
The three hosted Clara demonstrations remain unavailable locally.

Each prepared kit starts with fictional inputs, an ordinary first-use request,
a short outline, useful checkpoints and a practice change. The current workflow
produces the deliverable. Codex retains teacher and working conversations;
Cowork receives written lessons in one conversation. Prepared files and replayed
regression interpretations do not count as learner completion or professional
approval. Profiles and progress remain local; there is no added feedback service.

The browser lesson was executed through the shipped capability and process
runtimes in connected Chrome on the supplied fictional page. Two clean demo
replays finalized the local capability. Ten separate process attempts produced
the expected Invoice or Credit note confirmation across five lesson languages,
with model result reviews bound to the saved evidence. The page itself has
English controls. Separate CI regressions run the actual local HTML and native
driver in headless Chromium; their receipts remain unverified and cannot qualify
connected Chrome or a real portal. Ordinary-use performance qualification and
learner approvals are not fabricated.
