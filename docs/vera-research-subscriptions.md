# Optional existing research subscriptions

Vera can save the user's choice to use an existing Eutekne or One FISCALE
subscription, request an agentic access check and expose reported results in a
native MCP App. The publisher connection uses the current host's real tools,
including the user's signed-in browser. No publisher API or partnership is a
Vera prerequisite. There is no publisher-specific API integration or bundled
paid content collection.

The user's `Connect` click authorises relevant searches, reads and use of
passages in the current host model. Login/MFA remains with the user. The panel
hands the check to the same chat through `ui/message` when supported; otherwise
the saved choice is usable from chat. Connecting is not authenticated access.
A reported document read is historical; every research run checks current access.

The register is per computer profile, with optional trusted-host
`MPARANZA_RESEARCH_HOME` override. It stores no credentials or session state.
The user can disconnect without removing already retained case evidence. CAS
revisions and request IDs prevent stale checks from reviving disconnected access.
The helper does not run a browser, make network/model calls or validate page meaning.

The ordinary legal/tax journey reads the choices automatically. Research uses
the same agentic investigation, continuous validation/challenge and final review;
unsubscribed users do not enter setup. Actual paid-source passages require the
same semantic assessment, original-source checks and adverse-evidence treatment
as other evidence, with retention limits stated explicitly. Public URL acquisition
must not stand in for access to a subscriber original.

Acceptance requires a fresh installed host with working browser/connector tools
and a user's subscription: connect, complete user login if needed, search an
actual issue, read the relevant subscriber original, inspect source provenance
and final review, disconnect, and verify that the next research avoids that
source. Synthetic store/UI tests cannot establish Eutekne or One FISCALE live
access, subscription entitlement or professional answer quality.
