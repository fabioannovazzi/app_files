# Vera local WhatsApp in Cowork

The installed Cowork package rejected a controlled self-chat test because the
builder injected a WhatsApp prohibition into every Vera skill and the projected
Studio Archive skill declared that route unavailable. The tools were registered,
but the existing UI helper used another host's computer-control API.

Vera 0.1.629 routes these requests to `whatsapp-cowork.md`. The host uses its own
native Computer Use tools, verifies the account and contact-info phone, preserves
existing drafts, and retains dispatch claims and evidence in the existing local
register. `vera_whatsapp_runtime` reports process host and storage metadata; it
is not proof of permission or UI access. The workflow must match that process to
the controlled native computer. It cannot substitute a cloud/session ledger.
Ordinary authorized one-to-one messages and controlled tests need no tax question
or Archive client-folder setup. File transfers require actual device-visible
bytes; an inaccessible cloud path does not become an attachment.

Mechanical rules remain appropriate for exact identity matching, immutable file
hashes, revisions, UI ownership and one-time dispatch. The host interprets UI and
message evidence; receipts do not independently authenticate WhatsApp delivery.

Validation:
- 16 local-register tests pass; coverage 85.62%, including host diagnostics,
  duplicate claims, restart persistence, UTF-8 transport and file changes.
- The Cowork route regression and four instruction/privacy projection tests pass.
- Codex, ChatGPT upload, Cowork and Antigravity builds align at 0.1.629.
- 24 Cowork and 25 Antigravity local MCP startup checks pass.

After integrating Vera 0.1.628, 230 focused tests and 19 Cowork contract tests
passed. An earlier broad Cowork test run exposed an existing reconciliation
reference containing another host's worker commands; that unrelated source and
its strict regression are unchanged by this fix.

Claude Desktop initially rejected private uploads with “Failed to load
marketplaces” and temporary authentication/service errors. Its own updater
confirmed the app was current. A later normal upload retry succeeded: the
existing private Vera installation was replaced and the UI showed version
0.1.629 enabled. Native Cowork send acceptance is being checked separately;
installation alone is not send or delivery proof. Windows native acceptance
remains deferred. No Marketplace publication is part of this repair.
