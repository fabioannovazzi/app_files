# Vera extra HTML retirement — 3 November 2026

## Scope and decisions

The installed 0.1.553 audit found 24 literal HTML files, although only five app resources were advertised. Vera's build now retains only the HTML shells for those five resources. The 0.1.554 release packages these changes from the canonical 0.1.553 source. Source, package and installed-host evidence remain separate.

| Surface | Decision | Preserved use |
| --- | --- | --- |
| Fourteen component review widgets | Remove from Vera's embedded copies and disable their resource reads | Native shared workspace; existing evidence, save/apply, receipts and regeneration engines |
| Module-level Bilancio workspace | Remove its duplicate HTML/CSS/JS and the extra product opener | Shared Bilancio route, area renderer, case service and source evidence |
| Prompt model-selection HTML | Remove | Optional model advice/confirmation remains available through existing tools and chat |
| Extra root course-chat HTML | Exclude obsolete copy | Registered course app uses the canonical courseware chat template |
| Six injected generic loopback reviews and specialized Open-items browser code | Strip HTTP, HTML rendering and CLI launch functions from Vera's embedded helper copies | Data loading, validations, exact decision persistence and application |
| Treasury localhost review | Delete source launcher and assets | Existing native Treasury editor and persistent session/CLI review engine |
| Construction intake form | Delete HTML template and port to versioned Markdown | Saved original answers, follow-up questions, parent digest and successor revision; no invented author/session/date |
| Management report localhost preview | Exclude the launcher from Vera and port verified reading into app-only MCP preview; preserve the independent helper used by Clara | Original report, receipt checks, exact revision, pinned month-switching script, opaque iframe with no network/forms/base URLs |
| Generated HTML reports, websites and normal export artifacts | Retain | Requested deliverables, rather than extra workflow editors |

The packaging transform is deliberately scoped to Vera. Independently distributed sibling plugins and their own MCP editors are not removed from the repository. Unknown future HTML templates produce a build diagnostic instead of being silently deleted. The retired paths are recorded in the generated `ui/retired-browser-interfaces.json`.
