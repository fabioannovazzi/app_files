## Repair

The canonical shared `verified_execution.py` preserves an indexed Journal
Sampling module and the original package index before collecting its executable
release. The destination is `runtime/journal-sampling-replay`, outside the idle
release store. It contains shipped code, no client data and no product launcher;
it is retained until explicitly removed. Every copied byte is checked against
the unchanged original index. Preservation failure keeps the original release
and reports the local failure without blocking current work.

Vouching can resolve that fixed archive, then closes the exact implementation
inventory and validates every original assurance receipt before a private,
read-only normalization replay. New calculations continue to use current code.
No historical receipt, report or source hash is rewritten. Removing the archive
or moving a case to a host without its historical code still requires restoring
verified code; the archive is not a cross-host backup or publisher attestation.

The skill now places the agent's actual evidence review before comparison,
records exact row/document/locator and evidenced direction bindings in the
working recipe, and preserves missing evidence and opposite-direction
mismatches. It does not invent human approval or select amounts to match an
expected answer.
