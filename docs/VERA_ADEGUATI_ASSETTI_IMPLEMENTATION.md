# Vera adeguati assetti implementation

## Scope and decisions

Implement one company-bound assessment of organizational, administrative and
accounting arrangements. Model-led interpretation evaluates proportionality,
operating evidence, uncertainty, consequences and actions. Mechanical code only
checks exact references, source/record digests, prior-run identity, decision
binding and append-only outputs. No adequacy score, automated certification,
crisis trigger classifier, external assignment or scheduled monitoring is added.

## Work plan

1. Define the skill, professional-source method and record contract.
2. Implement source-bound observations, findings, actions and prior-review records.
3. Register routing, archive, privacy, public explanation and package metadata.
4. Test missing evidence, informal functioning controls, unused policies,
   unresolved actions, tampering, cross-case histories and exact approval binding.
5. Rebuild affected host projections, verify drift and run applicable quality gates.
6. Release the authorized combined change through green CI, merge and git-managed
   server deployment; verify live pages and package hashes.

## Acceptance boundary

A valid record proves mechanical integrity only. Behavioral evaluation uses
contrasting synthetic cases and records the model's reasoning and limits.
Fresh installed Codex/Cowork acceptance, publication and deployment are separate
from local implementation and packaging. Server deployment was subsequently
authorized; Marketplace publication and installed-host behavioral acceptance
remain separate. The independent scenarios are explicitly unexecuted, not a
claim of successful model or professional acceptance.
