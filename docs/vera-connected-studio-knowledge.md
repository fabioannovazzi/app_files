# Optional connected studio knowledge in Vera

## Implemented scope

Vera consults an existing host-connected repository when the user requests it
or adopts a studio instruction requiring it for the task. It uses callable
search/read tools, reads the actual sources, preserves provenance and applies
the selected specialist's existing requirements. Without a repository, ordinary
Vera work continues. Vera supplies no Second Brain service, Microsoft 365
dependency, connector credentials, migration or repository synchronization.

Studio skills remain independently invoked. There is no external-skill routing,
precedence rule, delegation or handoff from Vera. The shared repository is an
evidence source, not an execution mechanism for those skills.

The contract is in
`plugins/vera/skills/vera/references/connected-studio-knowledge.md` and is reached
from the router and public professional wrappers, including direct specialist
invocation. Cowork replacements preserve that gate only for Vera's exposed
wrappers; shared component skills are unchanged. Course source receipts pin the
shared reference, while lessons continue to use their bound synthetic materials.
Professional workflow privacy manifests register the optional external read
boundary and model-visible source content.
